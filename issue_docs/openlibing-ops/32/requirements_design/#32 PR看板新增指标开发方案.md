# PR看板新增指标开发方案

## 一、需求概述

PR 看板需新增 **4个指标**，分别在 **PR层级** 和 **Repo层级** 两个维度展示：

| 指标         | PR层级         | Repo层级                     |
| ---------- | ------------ | -------------------------- |
| PR E2E时长   | ✅ PR E2E时长   | ✅ PR E2E平均时长、P50、P90、P95   |
| PR 流水线启动时长 | ✅ PR 流水线启动时长 | ✅ PR 流水线启动平均时长、P50、P90、P95 |
| PR 合入时长    | ✅ PR 合入时长    | ✅ PR 合入平均时长、P50、P90、P95    |
| E2E达标率     | -            | ✅ E2E达标率                   |

> **注意**：E2E达标率的PR层级展示依赖E2E目标配置（`code_repo_e2e_target_config`表），本次实现仅包含Repo层级。

```java
// PR E2E时长计算逻辑（代码中实时计算）
private String calculatePrE2eTime(LocalDateTime createdAt, LocalDateTime mergedAt) {
    if (createdAt == null || mergedAt == null) {
        return null;
    }
    long seconds = java.time.Duration.between(createdAt, mergedAt).getSeconds();
    return NumberUtil.timeNumberConvert(seconds);
}

// 构造函数中赋值
this.prE2eTime = calculatePrE2eTime(statistics.getCreatedAt(), statistics.getMergedAt());
this.pipelineStartupTime = NumberUtil.timeNumberConvert(statistics.getPipelineStartLeadTime());
this.mergeLeadTime = NumberUtil.timeNumberConvert(statistics.getMergeLeadTime());
```

### 3.5 工具类变更

#### NumberUtil.java

```java
// 新增Double类型重载方法（用于mergeLeadTimeAvg等DOUBLE类型字段）
public static String timeNumberConvert(Double time) {
    if (Objects.isNull(time)) {
        return null;
    }
    return DECIMAL_FORMAT_ONE.format(time / 60.0);
}
```

## 五、指标计算说明

### 5.1 PR E2E时长

| 维度     | 计算方式                                                                                              |
| ------ | ------------------------------------------------------------------------------------------------- |
| PR层级   | `createdAt` 与 `mergedAt` 的时间差（代码中实时计算）                                                            |
| Repo层级 | ETL以秒为单位汇聚`pr_e2e_avg_duration`字段，代码中通过`NumberUtil.timeNumberConvert()`转为分钟展示，XML查询时计算P50/P90/P95 |

### 5.2 PR 流水线启动时长

| 维度     | 计算方式                                                       |
| ------ | ---------------------------------------------------------- |
| PR层级   | 数据库`pipeline_start_lead_time`字段（秒），转换为分钟                   |
| Repo层级 | ETL汇聚的`pipeline_start_lead_time_avg`字段，XML查询时计算P50/P90/P95 |

> 计算逻辑：有评论取第一条compile评论时间与第一条流水线启动时间差；无评论取PR创建时间与流水线启动时间差。

### 5.3 PR 合入时长

| 维度     | 计算方式                                              |
| ------ | ------------------------------------------------- |
| PR层级   | 数据库`merge_lead_time`字段（秒），转换为分钟                   |
| Repo层级 | ETL汇聚的`merge_lead_time_avg`字段，XML查询时计算P50/P90/P95 |

> 计算逻辑：最后一条流水线完成时间到PR合入时间的间隔。

### 5.4 E2E达标率

| 维度     | 计算方式                                                                                           |
| ------ | ---------------------------------------------------------------------------------------------- |
| Repo层级 | `sum(e2e_meet_count) / sum(merged_count)`，代码中通过`NumberUtil.percentageConvert()`转为百分比（如"71.4%"） |

> PR层级达标率依赖E2E目标配置表，本次未实现。

## 七、注意事项

1. **数据库依赖**：Mapper XML中引用的`merge_lead_time_avg`、`pipeline_start_lead_time_avg`等字段，需要在数据库中添加相应列后才能正常查询。

2. **E2E达标率PR层级**：当前未实现PR层级的达标率展示，该功能需要结合E2E目标配置表（`code_repo_e2e_target_config`）进行后处理计算。

3. **时间单位统一**：

    - 数据库存储：秒
    - 代码计算：秒转分钟
    - 展示单位：分钟（min）

4. **NULL值处理**：所有新字段均已处理NULL情况，NumberUtil工具类支持null值安全转换。
