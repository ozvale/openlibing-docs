## 四、已知边界与拍板记录（不再追问）

| 事项                         | 结论                                                                                                                                                                                                 |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 版权正则                     | 有空格写法 `Copyright\s*\(c\)\s*\d{4}\s+Huawei`（v4.1，12 仓实测依据）                                                                                                                               |
| 分支口径                     | 只扫默认分支（sdi_repo_branch_info.default_branch，与 PR 看板新口径一致）；不用 show_branch                                                                                                          |
| DB token 密文                | 不处理；clone 认证失败自动回退匿名，受限仓（如 acl-extend）单仓跳过不阻断                                                                                                                            |
| GitHub 仓 workflow           | 不扫 `.github/`，DANGEROUS_WF/TOKEN_PERM/PACKAGING 恒 NA（设计口径，平台仅 gitcode）                                                                                                                 |
| workflow 解析失败            | 整指标 NA（不当 0 冤枉、不当 10 漏检）                                                                                                                                                               |
| COPYRIGHT 超限文件           | 超 8MB/不可读：分子分母均不计                                                                                                                                                                        |
| TOKEN_PERM 混合场景          | 12 仓 0 命中；命中时线性内插 + 人工复核（design.md v4.2 已记录）                                                                                                                                     |
| scancode 版本                | 32.x 与 3.x 输出格式均兼容                                                                                                                                                                           |
| SPDX 下载                    | URL 间歇超时，缓存回退 + `--spdx-list-file` 兜底                                                                                                                                                     |
| MCP 限制                     | 无法执行 CREATE/INSERT，建表需手动执行（影响任务 1）                                                                                                                                                 |
| VULNS 指标口径（2026-09-22） | rejected=关闭态不扣分（与 closed 同理）；cve_level None/空按最低档 Low 扣 1；源表 `is_overdue_statistics` 不采用（超期自行判定：未关闭且 plan_closed_time < NOW()）；无 CVE 记录（未覆盖 90 仓）→ NA |
