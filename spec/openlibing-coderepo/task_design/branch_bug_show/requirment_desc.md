# 背景

目前代码仓管理页面的分支管理功能中，没有展示具体分支的代码检查告警数，需要：在代码仓管理页面的分支管理tab页面中展示：具体分支的代码检查告警数，并且需要支持该指标跳转到代码检查页面查看详情，告警页面也要包含分支条件。

# 要点

1、分支管理的查询接口在：/repo/branch/list,你需要在该接口中新增字段来返回具体分支的代码检查告警数。
2、点击指标跳转应该交给前端来实现，后端设计不考虑跳转逻辑。
3、你只需要生成详细的设计报告，放在本文件夹下，暂时不需要实现代码。
4、代码仓管理的仓库管理tab中，已经默认展示默认分支的代码检查缺陷数，你可以参考里面的实现，具体接口在：/project-repo/query-repo
5、代码实现主要在仓库：openlibing-coderepo中。
