# 代码仓不参与运营备注能力

## 关联信息

- FE 需求名称：【openLiBing-coderepo】代码仓不参与运营时增加备注能力
- 目标仓：`openlibing-coderepo`（后端，基线 `master`，实现分支 `repo-operation-remark`）、`openlibing-web`（前端，基线 `beta_gamma`）
- 变更类型：前端页面 + 后端接口 + 表结构
- 流程模式：Full

## 需求背景

代码仓管理中提供「是否参与运营」开关，关闭后该仓库不纳入运营统计。当前关闭开关无需任何说明，运营人员难以判断仓库被排除的原因是外部仓库、停止维护、临时排除还是误操作，统计口径难以复核，也缺少可追溯的判定依据。

## 功能描述

### 做什么

1. 新增代码仓时，「是否参与运营」选择「否」必须填写备注；选择「是」不展示备注。
2. 编辑存量代码仓时，以本次保存的开关取值为准：只要为「否」就必须填写备注，与本次是否修改开关无关；为「是」不展示备注。
3. 开关由「否」改为「是」时，备注不再保留。
4. 批量编辑复用本迭代已有的「是否参与运营」批量能力，勾选后默认「是」，与单个新增一致；选择「否」时在同一编辑项内填写备注（原值同为「否」时即批量修改备注）。
5. 备注最多 200 字，仅当「是否参与运营」为「否」时展示；编辑弹窗可查看和修改。
6. 代码仓列表在「是否参与运营」列后新增「不参与运营备注」列。
7. 导出代码仓列表时包含「不参与运营备注」列。
8. 存量数据不做批量补录，也不主动通知；用户不编辑该仓时不产生任何影响。

### 不做什么

- 不参与运营备注列不参与列表筛选、排序能力。
- 不做备注历史留痕、审批流或独立备注管理页面。
- 不修改 `isParticipateOperation` 开关本身的语义、默认值和筛选逻辑。
- 不处理 `RepoDTO.remark` 这一现存未使用字段（保持原样，避免引入无关变更）。

## 验收标准

- [ ] 新增仓：选择「否」时展示备注且必填，为空保存失败并提示。
- [ ] 新增仓：选择「否」并填写备注后保存成功，编辑弹窗可查看。
- [ ] 新增仓：选择「是」时不展示备注，保存成功。
- [ ] 存量仓当前为「否」且无备注：编辑任意信息（含未修改开关）保存失败并提示补充备注；补充后保存成功。
- [ ] 存量仓当前为「否」且已有备注：编辑保存成功，备注可修改。
- [ ] 存量仓当前为「是」：编辑保存不展示备注，保存成功。
- [ ] 由「否」改为「是」：备注项消失，保存成功，原备注不再保留。
- [ ] 批量编辑：勾选「是否参与运营」默认「是」，与单个新增一致；选择「否」时才展示备注。
- [ ] 批量设置「否」未填备注：不允许提交并提示；填写后提交成功，所选仓库备注一致（原值同为「否」时即批量修改备注）。
- [ ] 批量设置「是」：提交成功，所选仓库备注不再保留。
- [ ] 批量编辑其他属性（不改开关）：开关与备注保持不变；若所选仓库中存在「否」且无备注，不允许提交并提示先补充备注。
- [ ] 导出代码仓列表：包含「不参与运营备注」列；无备注时显示占位符。
- [ ] 代码仓列表：不参与运营备注列位于「是否参与运营」列之后；有值显示内容，空值显示 `--`，超长时省略并可悬浮查看。
- [ ] 未被编辑的存量仓：不做任何强制与提示。

## 影响范围

| 仓                      | 影响                                                                             |
| ----------------------- | -------------------------------------------------------------------------------- |
| `openlibing-web`        | 新增/编辑代码仓弹窗、批量编辑属性弹窗、列表不参与运营备注列、表单校验与开关联动  |
| `openlibing-coderepo`   | 表字段、实体/DTO、Mapper、新增/编辑/批量编辑校验与落库、列表查询回显、Excel 导出 |
| `openlibing-gateway`    | 不涉及：复用现有 `/project-repo/*` 路由、鉴权与菜单权限锚点                      |
| `openlibing-framework`  | 不涉及：不改用户/角色/菜单/项目/仓库主数据公共能力                               |
| `openlibing-common`     | 不涉及：复用现有 `DataResult` 与校验能力                                         |
| Nacos / APIG / MQ / OBS | 不涉及：无新增配置、无新增接口、无异步链路                                       |
| 数据库                  | `repo_info` 新增可空不参与运营备注列，Liquibase 迁移                             |
| `openlibing-docs`       | 本 SPEC；若生成前端接口说明文档则归档 `api.md`                                   |
