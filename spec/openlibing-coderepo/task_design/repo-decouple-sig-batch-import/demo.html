代码仓管理与需求解耦 + SIG 组一键批量录入 · 页面原型
本原型展示关键交互：①项目级「全局配置」弹窗（三页签，集中管理公共账号 / 代码仓录入配置（sig-info.yaml 链接） / GitCode 角色映射）；②手动录入（输入链接自动检测 → 历史多项目录入且配置不同则先选择主仓、配置按主仓自动同步，可选择性删除 / 修改配置同步提示）；③SIG 组一键录入（先多选尚未录入当前项目的仓库 → 表格核对/编辑/删除 → 批量录入）；④代码仓列表（来源列 + 关联项目数列）。样式对齐 openlibing-web Element Plus 主色 #006be6。

sig-info.yaml 链接：
● 可用
