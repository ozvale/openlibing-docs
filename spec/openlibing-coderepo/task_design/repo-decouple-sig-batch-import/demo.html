代码仓管理与需求解耦 + SIG 组一键批量录入 · 页面原型
本原型展示关键交互：①项目级「全局配置」弹窗（三页签，集中管理公共账号 / 代码仓录入配置（sig-info.yaml 链接） / GitCode 角色映射）；②手动录入（输入链接自动检测 → 首次录入默认即主仓；命中多项目录入时表单按主仓配置自动同步、可选择性删除，未删除之前项目行时提示是否将当前仓设为主仓（主仓仅用于录入时一键同步））；③编辑代码仓配置（仅更新本行，不涉及主仓，不做 SIG 来源拦截）；④SIG 组一键录入（先多选尚未录入当前项目的仓库 → 表格核对/编辑/删除 → 批量录入）；⑤代码仓列表（关联项目数列）。样式对齐 openlibing-web Element Plus 主色 #006be6。

● 可用

是否需要将当前仓设为主仓？
主仓概念仅用于录入代码仓时一键同步配置项：后续其他项目录入该仓时，将按主仓配置一键同步；不参与扫描归属、不影响各项目行配置。
