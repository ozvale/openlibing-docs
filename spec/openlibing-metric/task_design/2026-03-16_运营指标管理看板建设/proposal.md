# 运营指标管理看板建设

## 需求背景

构建一套运营指标管理系统，用于管理和展示数字化运营相关的指标数据。系统需要支持指标的定义、编辑、查询、维度管理、领域分类等功能，同时提供数据资产表字段的元数据管理能力，支撑看板类页面的数据展示需求。

## 功能描述

### 1. 指标管理
- **指标新增与编辑查询**：支持创建新指标、编辑已有指标信息
- **指标维度管理**：管理指标关联的维度信息，支持维度的增删改查
- **指标领域管理**：管理指标所属的业务领域分类，支持领域的增删改查
- **筛选参数管理**：提供指标筛选选项的元数据响应结构
- **指标查询接口优化**：优化查询逻辑，支持多条件组合查询

### 2. 数据资产管理
- **数据资产表注册**：注册和管理数据资产表，支持表的元数据录入
- **表字段查询与编辑**：支持查看和编辑数据资产表的字段信息

### 3. 删除接口 - 逻辑删除
- 对指标、维度、领域等实体提供逻辑删除接口，标记状态而非物理删除

### 4. 联调问题修复
- **指标管理联调**：修复 Controller 逻辑、补充实体字段和错误码
- **元数据管理联调**：修复表注册查询逻辑、新增请求参数体、升级 common 版本

### 5. CodeCheck 问题消除
- 累计 7 轮修复，覆盖 Controller、Service、Entity、Mapper、测试类等全量代码层

### 6. 基础设施
- 接口路径统一添加 `/manage` 前缀
- 数据源切换 AOP 注解
- 测试类日志格式统一调整

## 验收标准

- [ ] 指标管理支持 CRUD 操作，维度与领域分类层级清晰
- [ ] 数据资产表字段支持查询与编辑，返回格式与前端约定一致
- [ ] 逻辑删除功能生效，删除后数据状态正确标记
- [ ] 筛选参数配置可在指标查询时正确返回
- [ ] CodeCheck 问题清零
- [ ] 接口路径统一前缀 `/manage` 配置正确

## 影响范围

- `api/controller/` — 全部 REST 接口层
- `domain/digital/` — 数字指标领域层（实体/Service/Mapper）
- `domain/dataasset/` — 数据资产领域层
- `infrastructure/aop/` — 数据源切面
- `infrastructure/response/` — 响应码枚举
- `resources/mapper/` — MyBatis Mapper XML
- `application.yaml` — 应用配置
- `pom.xml` — 依赖管理
