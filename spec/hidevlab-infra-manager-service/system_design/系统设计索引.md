# hidevlab-infra-manager-service 系统设计索引

本目录用于沉淀 `hidevlab-infra-manager-service` 的系统级设计。该服务是 HiDevLab 实验室平台的基础设施管理服务（Blue Service Agent），面向裸金属服务器（BMS）、FusionCompute 虚拟机、网络设备（交换机/防火墙）、VPN、对象存储（OBS）和 K8s 集群提供统一运维编排，充当上层业务平台与底层华为基础设施之间的自动化执行代理。服务无状态、无 DB。

## 模块架构

- **入口/路由层（hidevlab_blue_service.py）**: 主管理服务路由
  - BMS/BMC：`bms_restart`/`shutdown`/`start`、`set_pxe_boot`、`bmc_user_create/delete`
  - 网络配置：`api_configure_custom_network`
  - FusionCompute VM：`create_vm`/`delete_vm`/`stop_vm`/`create_vm`
  - K8s：`k8s_create`/`delete`
  - 安全组：`security_group_create/delete`
  - 防火墙：`create_vpn_radius_api`、`create_nat_mapping_api`、`add_cross_acl`
  - 交换机：核心 ACL、端口 shutdown/undo
  - OBS：`config_obsutil`

- **入口/路由层（freeradius.py）**: RADIUS 认证回调服务
  - `authorize`/`authenticate`/`postauth`/`accounting`

- **基础设施层（base/）**: `config`、`common`、`apollo_manager`、`decrypt`、`entity`、`logging_handler`

- **业务层（service/）**:
  - `bmc`: 裸金属 BMC Redfish 操作
  - `virtual_machine`: FusionCompute 虚拟机/K8s/安全组
  - `vpn_service_api`/`yunshan_vpn_service_api`/`vpn_service`: 防火墙（老款 USG / USG12004 云山）
  - `network_isolation`: 核心交换机 ACL
  - `config_network`: 主机网卡配置（Debian/CentOS）
  - `obs`/`port`: OBS 配置、交换机端口操作

- **工具层（tools/）**: `ssh`(paramiko)、`tool`

- **DTO 层（dto/）**: `fusion_compute`(VM/K8s 配置对象)、`k8s`、`firewall`

- **安全层（utils/）**: `auth_filter`(token+HW签名)、`security`(脱敏)
