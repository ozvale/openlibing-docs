# 版本级流水线看板新增E2E执行平均时长(去除重试)指标

## 需求背景
版本级流水线看板当前展示的"E2E执行平均时长"包含重试耗时，无法准确反映流水线实际执行效率。SRE和开发团队需要一个去除重试后的E2E执行时长指标来更准确地评估流水线执行效率。

## 功能描述
在版本级流水线看板中新增"去除重试"的E2E执行时长指标，具体包括：
- **Chart图表**：将"E2E执行平均时长"替换为"E2E执行平均时长(min)(去除重试)"
- **表格**：新增独立分组"E2E执行(去除重试)"，包含P50/P90/P95/平均/最长5个子列
- **不做什么**：不修改原有"E2E执行"分组及字段，保持向后兼容

## 验收标准
- [ ] Chart图表中"E2E执行平均时长"替换为"E2E执行平均时长(min)(去除重试)"
- [ ] 表格中新增独立分组"E2E执行(去除重试)"，包含P50/P90/P95/平均/最长5个子列
- [ ] 表格中仅"E2E执行平均时长(min)(去除重试)"默认展示，其余子列不默认展示
- [ ] 两个数据源表新增`efficiency_duration_ms`字段
- [ ] 后端两个接口(`/pipeline/version/chart`和`/common/detail`)返回去除重试的时长数据
- [ ] 字段为NULL时页面显示"-"或空值（不崩溃）

## 影响范围
| 仓库 | 影响模块 | 影响说明 |
|------|---------|---------|
| openlibing-ops | Mapper/Model/Resp/Handler | 后端两个接口新增字段返回 |
| openlibing-ops-web | 表格列定义/Chart组件/提示文案 | 前端新增展示列和替换Chart指标 |
| Doris DB | 2张事实表 | 新增`efficiency_duration_ms`字段 |
