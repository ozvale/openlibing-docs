# Remove Product Quality Whitelist

## 需求背景

产品质量模块当前使用 `pq_project_quality_owner` 全局白名单控制读、写及负责人维护权限。现阶段需要移除该白名单校验，后续待李冰系统权限方案确定后再接入新的权限校验。

## 功能描述

- 移除产品质量模块对 `pq_project_quality_owner` 的白名单查询和放行逻辑。
- 保留现有 token 身份校验，匿名请求仍拒绝访问。
- 保留权限服务作为后续李冰系统权限方案的统一接入点。
- 不变更数据库表、SQL、业务接口路径及响应结构。

## 验收标准

- [x] 具有有效 token 的用户不再因不在白名单中而被拒绝。
- [x] 无有效 token 的请求仍按现有异常语义拒绝。
- [x] 产品质量权限链路不再调用白名单 Mapper。
- [x] 相关测试通过，且代码中保留下一步接入李冰权限的 TODO。
