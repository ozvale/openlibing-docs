2. 交互与生成流程

① 用户详情页点击「导出」
② 前端POST /build-artifact/sec-option/detail/export（projectId + recordId）
③ 后端权限与归属校验 → framework 创建导出任务（type=SEC_OPTION_DETAIL）→ 返回任务 ID
④ 前端bus 事件 host-export-task 通知主站导出中心
⑤ 后端异步BUILDING → 写 Sheet1 → 分批写 Sheet2 → UPLOADING → 上传 OBS → SUCCESS / FAILED
⑥ 导出中心3 秒轮询进度，成功自动下载，失败展示原因

3. Excel 结构（一个文件，两个 Sheet）

Sheet1「扫描概览」顶部基础信息块（8 项键值，链接可点击）＋ 14 行选项明细（选项名/描述/满足数/实际参与数/检测结果（覆盖率）/已备案文件数/备案后结果（覆盖率））
Sheet2「文件扫描结果」每文件一行 × 16 列：文件名、文件路径、14 项选项（YES/NO/N/A）；命中备案的单元格附加「（已备案）」
