公式说明：
· 检测结果（覆盖率）= 满足数 ÷ 实际参与数 × 100%　　实际参与数 = 满足数 + 不满足数（即参与该项检测、且不判为 N/A 的文件数）
· 确认结果（覆盖率）= 备案后满足数 ÷ 实际参与数 × 100%　　备案后满足数 = 满足数 ± 备案对 NO/YES 文件的变更（未备案时 = 满足数，确认结果与检测结果一致）
导出功能说明
导出按钮位置：产物包详情页顶部按钮区，与"返回概览"、"待备案项列表"同组（按钮文本"导出"，主按钮样式 + 下载图标）。
导出后交互：点击导出 → 调用 POST /build-artifact/sec-option/export → 返回 exportTaskId → 右下角浮窗出现"生成中"状态 → 3 秒轮询 → 生成完毕自动下载 + 浮窗变"导出完成"。
Excel 结构：
· Sheet1 Summary：与上方"安全编译选项汇总"表完全一致（7 列：安全编译选项 / 描述 / 满足数 / 实际参与数 / 检测结果（覆盖率） / 已确认文件数 / 确认结果（覆盖率）），每个已扫描项一行。
· Sheet2 Detail：与"文件扫描结果总览"矩阵弹窗对齐，但每个扫描项拆为两列（{扫描项名} - 原始值 + {扫描项名} - 备案值）；未备案文件的备案值列置为空（空字符串，非 N/A）。
文件命名：安全编译选项_{packageName}_{yyyyMMdd_HHmmss}.xlsx
缓存复用：同一 recordId 重复点导出秒级返回（OBS copyObject 复用历史 SUCCESS 文件）。
下载中心：顶部"下载中心"按钮可查看所有导出历史（3 天内），含状态、文件名、创建时间、操作（重新下载 / 预览）。
