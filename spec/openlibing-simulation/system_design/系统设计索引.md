# openlibing-simulation 系统设计索引

本目录用于沉淀 `openlibing-simulation` 的系统级设计。该服务是 OpenLibing 仿真服务平台（蓝区）的后端业务服务，提供仿真引擎、qcow 镜像、服务器/附件等资源管理，以及 Qemu 任务编排、节点管理、YAML 配置管理、仿真验证任务与运营数据上报等能力。

- 服务端口：`8108`
- 技术栈：Java 21 + Spring Boot 3.4.5 + MyBatis(-Plus) + Liquibase
- 本索引与代码基线 `master@4f22896` 对齐

### 覆盖缺口

以下能力当前已实现但尚无对应系统设计文档，后续按需补充：

- 资源管理 CRUD（引擎 / qcow / 服务器 / 附件）——已有需求归档见 `task_design/sim-resource-crud/`

## 模块架构

### controller 层

对外 REST 接口，统一前缀 `/simulation`。

| Controller                     | 路径前缀                        | 能力                                                                            |
| ------------------------------ | ------------------------------- | ------------------------------------------------------------------------------- |
| `QemuTaskController`           | `/simulation/qemu`              | Qemu 任务创建、查询、关闭、环境视图、按节点获取 SSH 凭据                        |
| `EngineResourceController`     | `/simulation/manage/engine`     | 引擎基础信息增删改                                                              |
| `QcowResourceController`       | `/simulation/manage/qcow`       | qcow 信息增删改                                                                 |
| `ServerResourceController`     | `/simulation/manage/server`     | 服务器台账与扩展信息增删改（`basic/delete` 逻辑删除，`extend/delete` 物理删除） |
| `AttachmentResourceController` | `/simulation/manage/attachment` | 资源附件元数据增删改                                                            |
| `HealthController`             | `/simulation/health-check`      | 健康检查                                                                        |

删除类接口统一使用 POST（`/xxx/delete`），id 通过 `@RequestParam("id")` 传入；操作者取自请求头 `X-Openlibing-User`。

### filter 层

| Filter                         | Order | 职责                                                                                                                                                                      |
| ------------------------------ | ----- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `OperationLogFilter`           | 1     | 采集请求信息生成审计日志（`MANAGE_LOG` logger），含操作者、客户端 IP、业务任务 ID、执行结果                                                                               |
| `InternalSimulationAuthFilter` | 2     | 校验内部共享密钥头 `X-Openlibing-Internal-Token` 与机机身份头 `X-Openlibing-User`；健康检查路径免认证；`security.internal-auth.enabled=true` 时密钥缺失或解密失败一律拒绝 |

### service 层

| Service                                                                                                 | 职责                                                                                                     |
| ------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| `QemuTaskService`                                                                                       | Qemu 任务编排核心：任务创建、查询、关闭、环境视图、节点凭据获取                                          |
| `NodeManageService`                                                                                     | 节点分配与释放、资源动态计算、指定机器预检                                                               |
| `EngineInfoService`                                                                                     | 引擎详情与列表查询                                                                                       |
| `EngineResourceService` / `QcowResourceService` / `ServerResourceService` / `AttachmentResourceService` | 各类资源的增删改                                                                                         |
| `VirtualRealYamlService`                                                                                | YAML 配置管理                                                                                            |
| `QemuPatchService`                                                                                      | Qemu 补丁管理                                                                                            |
| `DistributedLockService`                                                                                | 数据库分布式锁：`acquireLock` / `renewLock` / `isLockActive` / `releaseLock`（释放需带 ownerToken 校验） |
| `ScheduleService`                                                                                       | 定时任务，当前承载 OBS 数据采集                                                                          |

### mapper 层

MyBatis 接口 + `src/main/resources/mapper/*.xml`，命名一一对应，共 10 组：

`EngineBasicInfoMapper`、`NodeManageMapper`、`QcowInfoMapper`、`QemuNodeInfoMapper`、`QemuPatchMapper`、`QemuTaskMapper`、`QemuYamlManageMapper`、`ResourceAttachmentMapper`、`ServerResourceMapper`、`SimulationVerificationTaskBaseMapper`

### entity 层

- `dto/`：请求 / 响应 DTO
- `nodemanage/`：服务器与节点管理实体
- `qemu/`：Qemu 相关实体
- `simulationverification/`：仿真验证任务实体
- 根目录：引擎、qcow、附件、审计日志等通用实体
- 本仓无独立 VO / Convertor 层

### config 层

| 配置类              | 职责                                                                        |
| ------------------- | --------------------------------------------------------------------------- |
| `DataSourceConfig`  | 主数据源（Hikari），密码经 `SecurityUtil.decrypt` 解密                      |
| `MyBatisPlusConfig` | 分页插件、`BlockAttackInnerInterceptor`、`createTime`/`updateTime` 自动填充 |

### aop 层

`DataSource` 注解 + `DataSourceAspect`，配合 `DynamicDataSourceContextHolder` 切换 `MYSQL` / `DORIS` 数据源。

### client 层

| 客户端                  | 职责                                                |
| ----------------------- | --------------------------------------------------- |
| `DashboardReportClient` | Feign 调用 `openlibing-framework`，上报运营看板数据 |
| `ObsUtilClient`         | 华为云 OBS 对象存储封装                             |

### utils 层

| 工具类                                                                | 职责                                      |
| --------------------------------------------------------------------- | ----------------------------------------- |
| `JschUtil`                                                            | SSH / SCP 连接与远程执行                  |
| `ShellEscapeUtils`                                                    | Shell 命令转义与白名单校验                |
| `AesGcmUtil`                                                          | AES-GCM 加解密                            |
| `SensitiveDataConverter`                                              | 日志脱敏，在 `logback-spring.xml` 中注册  |
| `HttpUtils` / `FileUtil` / `DateTimeUtils` / `Pages` / `CommmonUtils` | HTTP 调用、文件、日期时间、分页、通用工具 |

### schedule 层

`ScheduleTask#collectObsData` 采集 OBS 数据，执行前通过 `DistributedLockService` 抢分布式锁。注意：`@Scheduled` 注解已移除，该方法当前不会被调度器自动触发。

### 数据库

Liquibase 迁移脚本位于 `src/main/resources/db/changelog/v1.0.0/`，入口 `db.changelog.xml`，当前登记 21 个变更脚本：

`t_engine_basic_info`、`t_engine_extend_info`、`t_qcow_info`、`t_qemu_node_info`、`t_qemu_patch`、`t_qemu_run_script`、`t_qemu_task_config`、`t_qemu_task_view_info`、`t_qemu_yaml_content`、`t_qemu_yaml_manage`、`t_resource_attachment`、`data_init_matrix_engine`、`t_server_basic_info`、`t_server_extend_info`、`t_server_task`、`t_server_using`、`t_simulation_scene`、`t_simulation_subscene`、`t_simulation_verification_run_status`、`t_simulation_verification_task_base`、`distributed_lock`
