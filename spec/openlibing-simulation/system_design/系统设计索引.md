## 模块架构

- **controller层**: 对外 REST API 控制层，处理 HTTP 请求和响应
  - `NodeManageController`: 节点管理接口
  - `QemuTaskController`: QEMU 任务管理接口
  - `QemuYamlManageController`: YAML 配置管理接口
  - `EngineInfoController`: 引擎信息管理接口
  - `QemuPatchController`: 补丁管理接口
  - `HealthController`: 健康检查接口

- **service层**: 业务逻辑层
  - `NodeManageService`: 节点管理业务逻辑
  - `QemuTaskService`: QEMU 任务业务逻辑
  - `VirtualRealYamlService`: YAML 配置业务逻辑
  - `EngineInfoService`: 引擎信息业务逻辑
  - `HidevlabService`: 外部服务对接
  - `DistributedLockService`: 分布式锁服务

- **entity层**: 数据模型
  - `nodemanage/`: 节点管理相关实体
  - `qemu/`: QEMU 相关实体
  - `hidevlab/`: 外部对接相关实体
  - 通用实体类

- **mapper层**: 数据访问层，基于 MyBatis Plus

- **config层**: 配置类
  - `DataSourceConfig`: 多数据源配置
  - `MyBatisPlusConfig`: MyBatis Plus 配置
  - `RateLimitConfig`: 限流配置

- **aop层**: 切面处理
  - `DataSourceAspect`: 动态数据源切换切面

- **utils层**: 工具类
  - `JschUtil`: SSH 连接工具
  - `HttpUtils`: HTTP 请求工具
  - `FileUtil`: 文件操作工具
