# 发布评审单撤回功能

## 需求背景

发布基础功能中，用户提交评审单后（状态进入「评审中」或「发布签发中」），若发现内容需要修改，当前只能删除后重建，体验较差。增加撤回功能，允许提交后回退到编辑态（SAVE）再次修改，提升易用性。

线上评审与线下评审均支持撤回。撤回时仅回退评审单主状态，不重置评审项（release_field_items_review）的评审状态，已评审过的项无需重新评审。

## 验收标准

1. 提供 `POST /base/withdrawReleaseReview` 接口，入参 `userId`/`projectId`/`id`
2. 仅创建人（creatorId）可撤回，非创建人返回"无修改权限"
3. 评审单不存在时返回"该评审单不存在"
4. 所有状态均可撤回到编辑态（SAVE），不限制来源状态
5. 撤回不触碰评审项表（release_field_items_review），评审项状态保持不变
6. 撤回成功返回评审单 id
7. 遵循华为代码规范检查（G 系列规则），通过 pre-commit 全量门禁
