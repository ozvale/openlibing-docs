### 3. SSRF（#101、#117、#118、#119、#122）

- #117/#118/#119（奇美拉/渗透扫描批次 SSRF）：同上覆盖
- **评审撤回**：通用 `OutboundUrlValidator` 与 repoUrl 入库前校验影响现有 clone 链路，按评审意见 revert（`24f1fae1`、`2ad7c9c1`），保留点状校验方案
- #122（敏感信息 URL 传输）：访问令牌统一迁出 URL，改经 `Authorization Bearer` 请求头传递（`1527605c`）

- #85：发布验签命令注入整改、软链接提权整改（`8e6a7804`），clamscan 等外部命令保持数组传参

### 6. 凭证与敏感信息（#93、#110、#83、#86、#127）

- #93：HeaderTokenAspect 硬编码静态请求头令牌收敛为枚举常量（`e8dbb91e`）

- #83/#86：URL 硬编码清理、SSL/token 拼接整改、漏洞公告仓库链接前缀迁移 Nacos 配置中心（`935100ae`）

### 7. 证书与传输安全（#84、#130、#108、#105）

- #130/#131（EmailUtil SMTP SSL 证书验证绕过）：移除信任所有主机配置，强制校验服务器证书（`127e3148`）

### 8. 供应链与运行时加固（#104、#106、#85、#129）

- #104（CI 供应链投毒）：pre-commit 工作流改造，不再以 Secret 权限检出 PR 可控代码（配套 `57360b68` 门禁升级）
- #106：Actuator shutdown 端点关闭并收窄 Web 暴露（`758d00e3`），multipart 上限按需收敛
- #85：Dockerfile 构建期压缩包校验与高危二进制权限声明（`5e51f2f8`）；限流计数 Lua 原子 INCR+EXPIRE 修复全局永久封禁（`5b31efc9`，CWE-770）
- #129（奇美拉扫描）：随本批次各项治理闭环

### 9. 响应安全与低危合并（#107、#109、#121）

- #107：附件下载 Content-Disposition 使用编码后安全文件名（`7207ad69`）
- #109（低危合并：日志注入/SQL stdout/异常泄露/安全响应头/限流器）：分项落地，其中"全局安全响应头过滤器"经评审 revert（`70485f01`）
- #121（CSRF）：认证与请求头令牌收敛后，写接口均要求 Bearer 头携带令牌，URL 携带 token 的 CSRF 面消除

## 关键决策记录

1. **撤回优于硬上**：多类校验（统一 SSRF 校验器、响应头过滤器、Jenkins token 请求体迁移）在真实环境验证中影响现网链路，按评审意见回退并留痕，避免发布分支引入回归
2. **鉴权统一收敛**：删除自定义 RequiresPermissions 切面，统一为项目权限注解校验，避免两套判权体系并存
3. **场景限定显式化**：#108（TrustAll 无调用方）、#110（凭证返回范围）、JRE SHA256（镜像不可达）等按场景限定给出结论而非一刀切
