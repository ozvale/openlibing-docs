# HPM包签名验证服务（含openUBMC公钥验签）

## 需求背景

openUBMC 等嵌入式场景的软件包以 `.hpm`（HPM 包）格式发布，需要在发布前对软件包进行数字签名验证，确保包的完整性和来源可信。要求提供通用的 CMS/PKCS#7 签名验证能力，支持三种输入格式：

1. **ZIP 格式 HPM包** — 内部含签名文件的 CMS 验签
2. **二进制 HPM 格式（openUBMC）** — 按 ASCII Hex 头部描述表解析 Manifest 和 CMS 签名段
3. **ZIP 压缩包（内含 .hpm）** — 解压后提取 .hpm 文件再做 CMS 验签

## 验收标准

1. 提供 `POST /signed/verify` 接口，接收 `hpmFile`（.hpm/.zip）和 `crtFile`（.crt）两个文件上传
2. 支持 ZIP 格式 HPM 包的 CMS 签名验证
3. 支持二进制 HPM 格式（openUBMC）的 ASCII Hex 解析 + CMS 签名验证
4. 支持 ZIP 压缩包（内含 .hpm）的解压后验签
5. 返回结果包含是否验证通过、算法、证书主体/签发者、有效期等详情
6. 提供内置 Service 接口（字节数组方式），供其他服务调用
7. 接口使用漏桶限流（`@LeakyBucketRateLimiter`，rate=3, capacity=5）
8. 遵循华为代码规范检查（G 系列规则）
9. 已有单元测试覆盖
