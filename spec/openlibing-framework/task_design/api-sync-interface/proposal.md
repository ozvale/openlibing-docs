# 对接接口管理服务，获取全量接口

## 需求背景

openLiBing 需要自动感知全量接口，实现接口权限的自动化配置和管理。当前接口权限管理依赖手动维护，效率低且易遗漏。通过对接外部接口管理服务，自动获取全量接口数据，实现接口的自动同步、白名单管理、URL标识管理和权限配置。

## 功能描述

### 做什么
1. **对接接口管理服务**：通过 Feign 客户端对接外部接口管理服务，获取全量接口数据
2. **接口数据同步**：定时同步接口管理服务的接口数据到本地数据库
3. **接口标识管理**：自动识别已下线接口（flag=0）和正常接口（flag=1），支持按 flag 过滤
4. **菜单 URL 同步**：新增/更新菜单 URL 时，自动匹配 service_interface_info 标识
5. **白名单接口管理**：网关特例放行接口的 CRUD 功能，支持模糊搜索和白名单标识必选校验
6. **误报接口管理**：支持撤销误报接口标注，补充日志切面处理
7. **角色权限 URL 查询**：支持按角色 ID 和菜单 URL 模糊查询分页返回
8. **API 兼容性扫描**：新增 API 扫描工作流，检测接口兼容性变更

### 不做什么
- 不涉及前端 UI 变更
- 不涉及接口管理服务本身的开发
- 不涉及已有接口权限数据的迁移

## 验收标准

- [ ] 接口管理服务 Feign 客户端可正常调用，获取全量接口数据
- [ ] 定时同步任务可按配置频率执行，增量同步接口数据
