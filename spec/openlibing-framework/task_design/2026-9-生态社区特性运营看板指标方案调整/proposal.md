# 生态社区特性运营看板框架特性指标方案调整

## 需求背景

`openlibing-framework` 既有「生态社区特性运营看板」按原指标方案提供框架特性指标数据展示。随着生态运营演进，原方案的指标类型、聚合方式、目标值维度已无法满足运营场景需求：

- 指标类型需区分为「数值」和「比率」两类（区别上报表数据时的数据结构）
- 聚合方式需可选「求和」「平均」「不聚合」（区分一个时间段内数据如何聚合）
- 全部列的计算方式需统一为「求和」「平均」（区分社区之间的数据如何聚合）
- 指标是否在特性详情展示需可配置（有些指标只有全部列才体现）
- 目标值支持可选，目标值可分别为「特性维度指标」「社区维度指标」并支持「增长目标值/消减目标值」（增长越大越好，消减越小越好）

本需求在 openlibing-framework 仓对特性指标元数据模型与上报接口做方案调整，支撑后续运营看板的可配置化展示。

## 功能描述

### 做什么

1. **指标元数据模型调整**：指标类型字段由单值调整为「数值/比率」二分类；聚合方式字段新增「求和/平均/不聚合」三选项；新增「是否在特性详情展示」开关字段。
2. **目标值模型调整**：目标值改为可选；目标值维度拆分为「特性维度指标」「社区维度指标」；目标值类型新增「增长目标值/消减目标值」二分类。
3. **全部列计算方式收敛**：全部列的聚合计算方式固定为「求和」「平均」，与「指标聚合方式」字段解耦。
4. **上报接口契约调整**：特性指标数据上报接口字段同步调整，兼容历史数据上报。

### 不做什么

1. 不重构前端运营看板页面布局，仅做字段对接适配。
2. 不迁移历史指标元数据（存量元数据沿用原值，运营按需手动调整）。
3. 不引入新数据库表，仅扩字段。
