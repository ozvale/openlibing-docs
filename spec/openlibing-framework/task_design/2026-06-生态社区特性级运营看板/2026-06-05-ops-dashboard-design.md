## 1. 设计概述

### 1.1 背景

openLiBing 是支撑研发流程的大型工作流平台，提供门禁检查、接口兼容性、流水线、测试框架、SBOM、漏洞视图、发布评审、工具市场、AI agent、Skill市场、数字化运营看板等特性。需要设计一个运营看板，展示这些特性在各开源社区的覆盖和对接进展。

### 1.2 核心定位

- **用途：** 运营跟踪管理工具，帮助运营团队跟踪各社区对接进展
- **风格：** 数据可视化风格，清晰展示特性覆盖情况
- **形式：** 先做静态 Demo 展示，后续可对接真实数据源

### 1.3 目标社区（行）

- MindIE
- PTA
- MindSpeed
- openEuler
- HPCkit
- UBS Core
- openUBMC
- CANN
- openLiBing（自身）

共 9 个开源社区。

### 1.4 目标特性（列）

- 门禁检查
- 接口兼容性
- 流水线
- 测试框架
- SBOM
- 漏洞视图
- 发布评审
- 工具市场
- AI agent
- Skill市场
- 数字化运营看板

共 11 个特性。

## 2. 页面结构与布局设计

### 2.1 整体布局

采用两段式简洁结构：

```
┌─────────────────────────────────────────────────┐
│  Header: 标题栏                                   │
│  openLiBing 特性覆盖看板                          │
├─────────────────────────────────────────────────┤
│  Main: 状态矩阵表格                                │
│  ┌─────┬──────┬──────┬──────┬─────...           │
│  │社区 │特性1 │特性2 │特性3 │                    │
│  ├─────┼──────┼──────┼──────┼─────...           │
│  │M1   │  🟢  │  🟡  │  ⚪  │                    │
│  │M2   │  ⚪  │  🟢  │  🟢  │                    │
│  └─────┴──────┴──────┴──────┴─────...           │
├─────────────────────────────────────────────────┤
│  Footer: 图例说明                                 │
│  🟢 已使用  🟡 对接中  ⚪ 未使用                  │
└─────────────────────────────────────────────────┘
```

### 2.2 Header 区域

- **固定高度：** 80px
- **背景：** 白色（#ffffff）+ 底部浅蓝边框（1px，#3b82f6）
- **标题：**
  - 文字："openLiBing 特性覆盖看板"
  - 字体：24px，粗体，深蓝色（#1e40af）
  - 左对齐，左侧可加 openLiBing logo（可选）
- **布局：** 无统计卡片，简洁清爽

### 2.3 Main 区域（表格）

**表格尺寸：**
- 行高：60px
- 列宽：
  - 社区名称列：150px（固定）
  - 特性列：100px（自适应）

**表格结构：**
- 表头：固定背景，显示社区 + 11 个特性名称
- 表体：9 行（对应 9 个社区）
- 表格单元格：居中显示状态灯

**滚动机制：**
- 桌面端（宽度 > 1400px）：完整展示所有列
- 中等屏幕（1400px - 768px）：特性列可横向滚动，社区列固定
- 移动端（< 768px）：简化表格样式

### 2.4 Footer 区域

- **固定高度：** 60px
- **背景：** 白色（#ffffff）+ 顶部浅蓝边框（1px，#3b82f6）
- **图例说明：**
  - 🟢 已使用（深蓝文字，#1e40af）
  - 🟡 对接中（深蓝文字，#1e40af）
  - ⚪ 未使用（深蓝文字，#1e40af）
- **排列方式：** 横向排列，居中显示

## 3. 交互设计

### 3.1 状态灯设计

**视觉效果：**
- 形状：圆形
- 直径：40px
- Hover 状态：放大至 45px

**三种状态：**

| 状态   | 内圈颜色 | 外圈颜色 | 外发光阴影                          | 含义     |
|--------|----------|----------|-------------------------------------|----------|
| 绿色   | #4ade80  | #22c55e  | 0 0 15px rgba(74, 222, 128, 0.6)  | 已使用   |
| 黄色   | #fbbf24  | #f59e0b  | 0 0 15px rgba(251, 191, 36, 0.6)  | 对接中   |
| 灰色   | #d1d5db  | #9ca3af  | 无                                  | 未使用   |

**Hover 效果：**
- 灯泡放大：从 40px 到 45px
- Tooltip 提示："点击查看详情"
- 蓝色光晕边框：#3b82f6
- 过渡时间：0.2 秒

### 3.2 点击交互 - 详情卡片

**触发：** 点击任意状态灯

**卡片尺寸：**
- 宽度：480px
- 高度：自适应（根据指标数量）
- 最大高度：500px（超出时可滚动）

**卡片内容结构：**

```
┌──────────────────────────────────────────┐
│  对接详情                                  │
├──────────────────────────────────────────┤
│  社区：MindIE                              │
│  特性：门禁检查                             │
│  状态：已使用 🟢                            │
│  ───────────────────────────              │
│  📊 用户指标                                │
│  ┌────────────┬────────────┐              │
│  │ 用户数(UV) │  156 人     │              │
│  │ 访问量(PV) │  1,234 次   │              │
│  └────────────┴────────────┘              │
│  ───────────────────────────              │
│  📈 业务指标                                │
│  ┌────────────┬────────────┐              │
│  │ 门禁平均时长│  12.5 分钟 │              │
│  │ 门禁拦截率  │  23.4%    │              │
│  │ 门禁成功率  │  96.7%    │              │
│  └────────────┴────────────┘              │
│  ───────────────────────────              │
│  备注：已完成门禁规则配置...                │
│  ───────────────────────────              │
│  [关闭]  [编辑]                            │
└──────────────────────────────────────────┘
```

**内容区域划分：**

1. **基础信息区**（100px）
   - 社区名称、特性名称、当前状态（带状态灯图标）

2. **用户指标区**（100px）
   - 图标：📊 用户指标
   - 统一展示所有特性：
     - 用户数（UV）：数字展示，如"156 人"
     - 访问量（PV）：数字展示，如"1,234 次"
   - 表格布局，两列展示
   - 数据样式：18px 粗体蓝色 + 单位标注

3. **业务指标区**（自适应）
   - 图标：📈 业务指标
   - 展示特性专属业务指标（见 3.3）
   - 表格布局，指标名称 + 数值
   - 百分比数据：带迷你进度条可视化

4. **备注信息区**（80px）
   - 多行文本展示
   - 灰色状态："暂未对接，如有需求请联系运营团队"

5. **操作按钮区**（50px）
   - "关闭" 按钮 + "编辑" 按钮（灰色状态隐藏编辑按钮）

**卡片样式：**
- 背景：白色（#ffffff）
- 边框：蓝色边框（#3b82f6，2px）
- 阴影：0 10px 25px rgba(59, 130, 246, 0.15)
- 标题区背景：浅蓝色（#eff6ff）
- 弹出动画：淡入 + 轻微上移，过渡 0.3 秒
- 关闭动画：淡出效果，过渡 0.2 秒
- 半透明遮罩层：背景变暗（rgba(0, 0, 0, 0.3))

## 6. 技术实现要点

### 6.1 技术栈

- **HTML5：** 页面结构
- **CSS3：** 样式设计（Grid/Flexbox 布局）
- **JavaScript：** 交互逻辑（详情卡片弹窗）
- **SVG/CSS：** 状态灯圆形设计

### 6.2 关键技术点

**布局实现：**
- 使用 CSS Grid 实现表格布局
- 社区列使用 `position: sticky` 固定左侧
- 特性列横向滚动使用 `overflow-x: auto`

**状态灯实现：**
- CSS 圆形（border-radius: 50%）
- CSS radial-gradient 渐变
- CSS box-shadow 外发光效果
- Hover 使用 transform: scale() + 过渡动画

**详情卡片实现：**
- Modal 弹窗组件
- 点击事件监听
- 数据填充与渲染
- 关闭事件与遮罩层管理

**响应式设计：**
- 媒体查询（@media）适配不同屏幕
- 移动端简化布局

### 6.3 文件结构

```
ops-dashboard-demo/
├── index.html          # 主页面
├── styles/
│   └── main.css        # 主样式文件
├── scripts/
│   ├── main.js         # 主逻辑脚本
│   └── data.js         # Mock 数据
└── assets/
    └── logo.png        # openLiBing logo（可选）
```

### 6.4 性能优化

- CSS 动画使用 transform 和 opacity（GPU 加速）
- 详情卡片数据缓存
- 防抖处理横向滚动事件
- 按需渲染详情卡片内容
