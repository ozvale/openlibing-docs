# hidevlab-foreman-service 系统设计索引

本目录用于沉淀 `hidevlab-foreman-service` 的系统级设计。该服务是 HiDevLab 平台对接开源 Foreman（裸金属/物理机装机管理平台）的适配代理层，向上经 APIG 网关对 BMS Agent 暴露 REST 接口，向下调用 Foreman REST API 完成物理机的创建、删除与装机完成回调通知。服务自身无状态、不持久化业务数据。

## 模块架构

- **入口/路由层（foreman.py）**: Flask 应用入口与路由
  - `bms_delivery`: 创建 Foreman Host（裸金属装机交付）
  - `bms_delete_host`: 删除 Foreman Host
  - `install_complete`: Foreman 装机完成回调入口
  - `health_check`: 健康检查

- **基础设施层（base/）**: 鉴权、配置、解密、日志、通用响应
  - `auth_filter`: token 校验与 HW 签名（`auth_filter`/`sign_request`/`get_sign`）
  - `config`: ReturnCode 与 Apollo 配置常量
  - `apollo_manager`: `SecureApolloClient` 配置中心客户端
  - `decrypt`: 双密钥异或 + PBKDF2 + AES-GCM 解密
  - `logging_handler`: JSON 格式按天滚动日志与脱敏
  - `common`: 统一返回体 `return_post`

- **业务层（service/）**: 业务逻辑
  - `host_manage`: 物理机创建/删除（`create`/`delete`）
  - `bms_agent_manage`: 装机完成回调通知（`delivery_complete`）

- **工具层（utils/）**: `mask_string`、`random_string`、`regex_util`
