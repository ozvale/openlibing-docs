# computing-resource-workspace 系统设计索引

本目录沉淀 `computing-resource-workspace` 的系统级设计。该仓承载两大业务板块：一站式作业和灵枢作业平台（AI作业平台）。

## 仓库定位

`computing-resource-workspace` 是 OpenLiBing 平台的**计算资源工作区服务**，基于 Spring Boot 构建（Java 21），对外提供 REST API。承载两大业务板块：一站式作业（IDE 插件后端）和灵枢作业平台（网页端），面向蓝区用户提供计算环境申请、任务执行和 AI 模型推理代理能力。

## 业务板块

| 板块 | 说明 | 详细设计 |
|------|------|---------|
| 一站式作业 | IDE 插件后端，环境申请 → 软件安装 → 任务执行 → 资源释放的完整闭环，对接 HiDevLab | [一站式作业系统设计.md](一站式作业系统设计.md) |
| 灵枢作业平台 | 项目空间管理 + MaaS 模型推理代理，前端为网页端 | [AI作业平台系统设计.md](AI作业平台系统设计.md) |

## 技术栈

| 类别 | 选型 |
|------|------|
| 语言 / 框架 | Java 21 / Spring Boot |
| ORM | MyBatis-Plus |
| 缓存 | Redis（分布式锁、限流计数、用户信息缓存、API Key 验证缓存） |
| 数据库 | MySQL |
| HTTP 客户端 | OkHttp（HiDevLab 调用）、JSch（SSH 远程执行） |
| 配置中心 | Apollo |
| 日志 | LTS（日志入湖）+ logback |
| 公共依赖 | openlibing-common-sdk |

## 鉴权体系

系统存在三套独立鉴权拦截器，服务于不同业务场景：

| 拦截器 | 路径 | 鉴权方式 | 适用板块 |
|--------|------|---------|---------|
| AuthInterceptor | `/api/env/**`, `/api/plan/**`, `/api/task/**` | Cookie + HiDevLab 权限校验 | 一站式作业 |
| OpenlibingAuthInterceptor | `/api/maas/**`, `/api/project/**`, `/api/monitor/**`（排除 `/api/maas/v1/**`） | JWT Token | AI 作业平台管理接口 |
| MaasAuthInterceptor | `/api/maas/v1/**` | API Key (Bearer Token) | MaaS 模型调用 |

另有 `ApiRateLimitInterceptor`（管理接口限流）和 `HealthRateLimitInterceptor`（健康检查端点限流）。

## 外部依赖

| 依赖 | 用途 |
|------|------|
| HiDevLab | 环境创建/查询/释放/任务执行（HMAC 签名鉴权） |

| openlibing-gateway | JWT Token 验证、用户身份注入 |
