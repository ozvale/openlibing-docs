# hidevlab-transport-service 系统设计索引

本目录用于沉淀 `hidevlab-transport-service` 的系统级设计。该服务是 HiDevLab 体系中控制面与计算节点/Agent 之间的代理网关，向上对接 APIG/业务后端，向下通过 SSH 操作宿主机、通过 HTTP 调用 host 上的 Agent，负责远程执行脚本、传输文件、管理 Docker 容器环境。服务无状态、不直连数据库，任务态存于内存+临时文件。

## 模块架构

- **入口/路由层（transport.py）**: Flask 路由
  - 健康检查：`health_check`
  - Agent 转发：`agent_get_token`、`set_agent_interval`、`delete_net_config`、`delete_agent`、`transport_metrics`
  - 软件预装：`software_install/uninstall/status_check`
  - Docker 生命周期：`docker_create`/`restore`/`stop`/`remove`/`image_save`
  - 自定义镜像：`docker_custom_image_pull`
  - 镜像发布：`docker_image_publish/unpublish`
  - 网络隔离：`docker_block_add/delete`
  - CANN：`docker_cann_update`/`query`
  - OBS：`set_vm_obs`

- **基础设施层（base/）**: `config`(Apollo 聚合)、`apollo_manager`、`auth_filter`(鉴权签名)、`decrypt`(AES-GCM)、`common`(响应封装)、`logging_handler`

- **业务层（service/）**:
  - `docker_manager`: `DockerManager`（SSH+docker CLI 封装）+ 一组 `async_*` 编排函数
  - `obs`: OBS obsutil 配置
  - `pre_install`: 软件安装状态判定
  - `docker_config/`: 容器初始化脚本

- **安全工具层（utils/）**: `command_security`(`CommandSecurity` 命令注入防护)、`security`

- **工具层（tools/）**: `ssh`(paramiko)、`json2file`
