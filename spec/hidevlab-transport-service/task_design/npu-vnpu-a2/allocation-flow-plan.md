# A2 创建前拓扑准备与实际绑定回调修订

关联：openlibing/hidevlab-transport-service#120、PR #186。沿用已确认的 Full 模式及现有业务/docs 分支。

## 目标与生成约束

按用户 2026-10-22 明确的流程实施，仅支持 A2 非双芯。PHY 请求先遍历并回收整张父芯片上均未使用的 vNPU；VNPU 请求先匹配实际模板和空闲实例，没有足够可用实例时选择空闲父芯片按同一模板创建到资源耗尽，再继续既有容器流程。创建/restart 成功回调必须提供当前容器实际使用的物理/vNPU ID。

保留全量 Docker 引用（含停止容器）、驱动/宿主机占用检查、容器→全局→芯片锁、generation、事务回滚与未知状态隔离。移除固定 K、模板 capacity plan 和整组验证记录的准入条件；账本记录实际发现/创建的拓扑。双芯仅维护业务 docs 建议。不变更其他代际整卡分配算法。

## 验证要点

资源耗尽只接受明确证据；未知 create 错误、假成功、查询失败不能当作切满。内存 Free 包含系统占用，不能用模板内存直接计算最大实例数。回滚仅处理本事务新建实例。已有相同模板即使未完整切满也可复用；已有占用、异模板实例和其他容器的绑定不得被改写。模拟测试不代表真实硬件验收。
