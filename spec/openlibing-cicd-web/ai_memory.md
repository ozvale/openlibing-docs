# openlibing-cicd-web AI Memory

本文档保存 `openlibing-cicd-web` 代码仓可长期复用的 AI 开发规则。当前为初始版本，后续从已验证的需求归档中提炼。

## 仓库定位

`openlibing-cicd-web` 负责 OpenLibing 流水线子应用前端能力，包括流水线详情、流水线编辑、事件触发、日志导出、任务执行状态和耗时展示。

## 稳定规则

- AI 开发前应先读取当前需求目录下的 `specs/*/spec.md`。
- 涉及流水线详情、编辑表单、事件触发、日志导出或子应用生命周期时，应同步检查相关能力规格。
- 需求完成后，如产生可复用规则，再补充到本文件，避免记录未经验证的临时判断。
