# Proposal: 流水线历史记录表格新增 Merge ID 列

## 需求背景

流水线详情页的历史记录表格当前展示执行信息、状态、触发方式、工作流、执行时间/时长和参数列，缺少 Merge ID 信息。用户在排查 PR 触发的构建时，无法直接通过 Merge ID 定位和查看对应的合并请求详情，需要手动切换到代码托管平台查找，效率较低。

## 需求目标

在流水线历史记录表格中新增 Merge ID 列，提供以下能力：

1. **展示**：以 `#<merge_id>` 格式显示 Merge ID，无值时显示 `--`
2. **筛选**：列头支持文本筛选，输入 Merge ID 后过滤历史记录
3. **跳转**：点击 Merge ID 链接跳转至代码托管平台对应的 MR/PR 详情页
4. **空值处理**：筛选框为空时不向 API 传递 `mergeId` 参数，避免误过滤

## 验收标准

- [ ] 历史记录表格正确展示 Merge ID 列，列宽 120px
- [ ] 有 Merge ID 的记录显示 `#<id>` 可点击链接，无值显示 `--`
- [ ] 点击链接在新窗口打开代码托管平台对应的 MR/PR 页面
- [ ] 列头文本筛选输入值后，API 请求正确携带 `mergeId` 参数
- [ ] 筛选框清空后，API 请求不携带 `mergeId` 参数
- [ ] 不影响现有其他列的筛选、排序和展示

## 影响范围

- 前端：`openlibing-cicd-web` 仓 `History.vue` 组件
- 后端：无变更（`mergeId` 筛选参数由现有 API 已支持）
