# Proposal: 测试结果组件新增执行中状态展示与刷新按钮

## 需求背景

流水线详情页测试结果（TestResult）组件当前只展示"通过"和"失败"两种用例状态，缺少"执行中"状态的展示。用户在用例执行过程中无法看到正在运行的用例数量，也无法手动刷新查看最新执行进展，可观测性不足。

## 需求描述

1. 新增 running 状态在表头筛选下拉与状态映射中的处理，状态文案统一为"执行中"
2. 同步 getStateDotClass 圆点颜色映射，使执行中状态有正确的颜色标识
3. 测试结果摘要栏新增"执行中"用例计数显示
4. 摘要栏新增刷新按钮，调用 loadData 重拉当前筛选条件下的列表数据

## 验收标准

- [ ] 状态筛选下拉中包含"执行中"选项，文案为"执行中"
- [ ] 表格中执行中状态的用例行显示正确的状态文案与圆点颜色
- [ ] 摘要栏显示"执行中：N"计数
- [ ] 刷新按钮点击后数据正确刷新，刷新期间按钮显示 loading 状态
- [ ] 不影响现有通过/失败状态的展示与筛选
