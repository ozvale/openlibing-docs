## 可复用经验

- 华为云流水线接口返回的 `variables` 数组包含 `is_runtime` 字段用于区分运行时/非运行时参数
- 非运行时参数不允许编辑，仅展示文本，提交时仍需提交（后端处理）
- `type` 字段支持 `enum`/`string`/`autoIncrement` 三种类型，`enum` 类型通过 `limits` 字段提供可选值列表
