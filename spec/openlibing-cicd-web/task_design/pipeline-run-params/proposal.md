# 流水线运行参数表单优化

## 需求背景

流水线运行弹窗中的参数配置表单存在以下问题：

1. 华为云流水线接口返回的变量包含 `is_runtime` 字段，标识是否为运行时参数。非运行时参数（如流水线级别的固定变量）不应在运行弹窗中编辑，但当前表单对所有参数一视同仁，允许编辑。
2. 华为云流水线接口返回的变量包含 `type` 字段（enum/string/autoIncrement），但当前表单硬编码为"字符串"类型，不支持枚举类型下拉选择。
3. 华为云流水线接口返回的变量包含 `description` 字段，但当前表单未展示描述信息，用户无法了解参数含义。
4. 表单样式简陋，缺少边框、行 hover 等交互反馈，视觉体验不佳。

## 验收标准

1. 非运行时参数（`is_runtime === false`）整行加深背景色，默认值列显示纯文本，hover 提示"非运行时参数，到华为云流水线修改"
2. 运行时参数优先显示在表单上方，非运行时参数排在下方
3. 类型列根据 `type` 字段映射显示：`enum` → 枚举、`string` → 字符串、`autoIncrement` → 自增长
4. 运行时参数且 `type === 'enum'` 时，默认值渲染为下拉选择框，选项来自 `limits` 字段
5. 新增描述列，从 `description` 字段取值，文本过长省略号 + hover 显示完整内容
6. 移除新增/删除参数按钮（非运行时参数不允许添加/删除）
7. 表单整体样式优化（边框、圆角、行 hover、间距对齐）
