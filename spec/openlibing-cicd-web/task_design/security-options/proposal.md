# Proposal: 安全编译选项数据工程能力建设

## 需求背景

当前安全编译选项（BN/NX/PIC/PIE/RELRO/NP/SP/STRIP）的检测数据缺乏前端展示页面，无法直观查看各代码仓的安全编译选项开启情况。需要建设安全编译选项概览页面，支持按代码仓、文件、时间范围筛选，提供数据下钻能力，帮助研发团队识别安全编译选项未达标的风险。

## 需求描述

1. 新增安全编译选项概览页面，以 el-tabs + el-table 布局展示各代码仓的安全编译选项检测数据
2. 支持代码仓/文件联动下拉筛选，文件下拉依赖代码仓选择
3. 支持检测完成时间范围筛选（datetimerange 选择器）
4. 支持文件详情下钻弹窗，查看单个文件的安全编译选项明细
5. 支持表格自定义排序（sortByField/sort）
6. 代码仓/流水线/文件三列固定在左侧

## 验收标准

- [ ] 安全编译选项概览页面正常渲染，数据展示正确
- [ ] 代码仓下拉筛选数据来源于 dropdown 接口 data.repoNames
- [ ] 文件下拉筛选与代码仓联动，数据来源于 dropdown 接口 data.packageNames
- [ ] 检测完成时间范围筛选传入 startTime/endTime 参数
- [ ] 点击文件名弹出详情弹窗，展示文件级安全编译选项明细
- [ ] 弹窗内文件名支持模糊搜索
- [ ] 表格排序参数为 sortByField/sort 格式
- [ ] 代码仓/流水线/文件三列固定在左侧
- [ ] 流水线列支持跳转链接
