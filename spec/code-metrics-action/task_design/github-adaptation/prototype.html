设计关键点

不改扫描口径，只做平台适配与展示增强
01

上下文变量识别平台

启动时以 GITHUB_ACTIONS=true 一次判定平台：GitHub 只读 GITHUB_*，GitCode 只读 ATOMGIT_*，不跨平台混用，一份代码同时适配两平台。

02

OIDC 免密认证

GitHub 下自动切换身份提供商为 GitHubActions、信任委托为 github-actions，仓库不配置任何长期密钥。

03

摘要双通道

GitHub 写 GITHUB_STEP_SUMMARY，GitCode 写 ATOMGIT_STEP_SUMMARY，统一表格样式。

04

GitCode 原有链路兼容

上报接口、ATOMGIT_STEP_SUMMARY 摘要、ATOMGIT_OUTPUT 输出面板与详情下钻全部保持，存量工作流零改动。

05

依赖精简

移除未使用的 config-file/js-yaml 与 winston，产物体积下降约 513KB。

06

上报桶按平台隔离

GitCode 上传 openlibing-gitcode-action，GitHub 上传 openlibing-github-action；对象 key 结构一致，后端按桶名区分平台。

认证路径 B：AK/SK（已废弃） 仅用于测试仓临时验证，不写入对外文档；后续统一收敛到 OIDC。

范围边界

避免与其他 US 重叠

页面展示复用现有能力

分支管理页的指标展示与下钻沿用现有页面；GitHub 来源如需字段适配由前端配套 US 承接，本 US 保证上报数据准确、可解析。

不包含 PR 门禁

GitHub PR 质量门禁、趋势看板不在本期范围。

OIDC 依赖 IAM 配置

华为云侧需先完成 GitHubActions 身份提供商与信任委托配置。
