## 整改范围

### 1. 日志卫生（PR #38）

- `gitUrl` 内嵌凭证剥离，其余形态与原行为一致。
- 路径输出统一 basename，避免主机目录结构外泄。
- 日志内容做控制字符与换行清洗，防日志注入。

### 2. 命令执行加固（PR #39）

- `scc` / `pip` 调用改为 argv 数组传参，消除 shell 拼接注入面。
- 执行切换到受控临时目录，避免污染工作区。

### 3. 上传器卫生（PR #40）

- 清理不可达的回退分支。
- 临时文件权限收紧并按生命周期清理。
- 输入参数与 URL 收敛。

### 4. OBS 上传链路重构（PR #41）

- 从 `obsutil` CLI 迁移到 `esdk-obs-nodejs` SDK，消除外部命令依赖与凭证明文入命令行风险。
