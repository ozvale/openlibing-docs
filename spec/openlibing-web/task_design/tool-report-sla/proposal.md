# tool-report-sla

## 需求背景

工具管理 - 工具举报功能在待办中心展示时缺少「审核截止时间」和「是否已超时自动下架」两个关键信息，审核人员无法直观判断举报工单是否即将超时或已被自动下架处理。同时，工具详情页的举报状态显示逻辑存在缺陷：当 `reportStatus` 字段值不在 `0/1/2` 范围内时，会错误回退到「可举报」状态展示，与实际状态不符。

此外，待办中心提交工具举报审核后，顶部待办计数 `pendingReviewCount` 未同步递减，导致计数与实际待办数量不一致。

## 功能描述

1. 待办中心「工具举报申请」与「工具举报审核」两个列表新增：
   - 「审核截止时间」列（字段 `slaDeadline`）
   - 「是否已超时自动下架」列（字段 `slaExpired`，后端返回 `'1'` 时显示「是」，其他显示「否」）
2. 工具举报审核通过后，递减 `pendingReviewCount`，保持待办计数同步
3. 修复工具市场详情页举报状态显示逻辑：
   - `reportStatus === '2'` 显示「已下架」图标
   - `reportStatus === '1'` 显示「审核中」图标
   - `reportStatus === '0'` 显示举报入口（须具备 `tool_report` 权限）
   - 其他状态不显示任何举报相关元素（避免错误回退）

## 验收标准

- [ ] 待办中心 → 工具举报申请列表：展示「审核截止时间」「是否已超时自动下架」两列，数据正确
- [ ] 待办中心 → 工具举报审核列表：同上展示两列
- [ ] 「是否已超时自动下架」列：后端返回 `slaExpired === '1'` 显示「是」，其他值显示「否」
- [ ] 工具举报审核通过后，顶部 `pendingReviewCount` 计数 -1
- [ ] 工具市场详情页：`reportStatus` 为 `0/1/2` 时分别显示对应元素；其他值不显示任何举报相关元素

## 影响范围

- 模块：`openlibing-web` 仓待办中心（ToDoCenter）+ 工具管理详情页（ToolMarket）
- 文件：3 个 Vue 文件
- 接口：依赖后端新增 `slaDeadline`、`slaExpired` 字段返回
- 数据：无前端持久化数据变化
