# 需求背景

## 业务场景

菜单管理页面已完成 tabs 化改造（5 个 tab：菜单、未匹配接口列表、接口列表、访问白名单接口、人工配置接口）。原 tab 命名（已下线接口、误报接口）是从接口治理操作视角命名，与实际数据口径存在偏差，用户难以从名称直接理解各 tab 承载的数据范围。

## 问题痛点

1. **命名与数据口径不符**：「已下线接口」实际承载的是"菜单中配置但未出现在接口列表中的接口"，「误报接口」实际承载的是"人工确认过的有效配置接口"，名称易造成误解
2. **缺少口径说明**：各 tab 数据来源（如接口列表来自接口管理服务）无任何提示，用户需要口头咨询才能理解差异

## 需求目标

1. 修改 2 个 tab 名称：「已下线接口」→「未匹配接口列表」、「误报接口」→「人工配置接口」
2. 为 4 个 tab 名称旁增加问号提示（tooltip hover 显示）：
   - 未匹配接口列表：菜单中配置的接口，未在接口列表中的数据
   - 接口列表：提示数据由接口管理服务提供
   - 访问白名单接口：豁免/无需鉴权/无需登录的访问接口列表
   - 人工配置接口：未匹配接口列表中，人工已确认是有效配置的接口

## 验收标准

### 功能验收

1. **tab 改名**
   - tab 头显示：菜单、未匹配接口列表、接口列表、访问白名单接口、人工配置接口
   - tab 切换功能、内容懒加载不受影响（prop 值不变，仅 label 改名）

2. **问号提示**
   - 4 个 tab 名称右侧显示问号图标，鼠标悬停显示对应 tooltip 文案
   - 菜单 tab 无问号图标（无提示需求）
   - 问号样式：默认灰色、hover 蓝色，不遮挡 tab 文字与点击区域

### 非功能验收

1. 不影响 tab 内各页面既有功能（表格/分页/查询/操作）
2. 代码变更符合项目编码规范
