# 【openlibing-web】代码仓管理令牌体系重构

## 需求背景

代码仓管理页（Repos）此前的令牌能力存在以下问题：

- 令牌只支持"手动填写"一种方式，未配置令牌的仓库无法一键继承项目公共账号令牌，配置成本高
- 编辑已配置令牌的仓库时，令牌输入框直接可编辑，容易误改；且"输入为空将清除令牌"的语义不够直观
- 令牌是否有效、成员角色是否匹配、权限范围是否正确，在列表上不可见，需要逐仓排查
- 保存前缺少令牌权限预检，令牌权限不足（如成员角色不够、权限范围缺失）只有在后续操作失败时才暴露
- 平台限制不完整：代码风格自动修复此前仅对 github 禁用，gitee 实际同样不支持；告警抑制自动检视、接管 PR 管理等开关也存在类似残留问题
- "禁止合并自己的 PR""评审问题全部解决才能合并"两个配置项已下线，需要从表单与列表中移除
- 录入/编辑/批量编辑/全局配置弹窗点击遮罩会误关闭，丢失已填内容

本次对令牌体系进行整体重构：新增令牌类型（手动填写/继承自项目）复合输入与编辑锁定交互、保存前令牌权限检查、列表令牌信息筛选与状态列扩展，并统一收紧各托管平台的开关限制。

## 功能描述

### 令牌类型复合输入（手动填写 / 继承自项目）

- 录入/编辑弹窗"公共账号令牌"输入框前置类型下拉：手动填写（manual）/ 继承自项目（inherit）
- 继承态：输入框禁用并传空（后端以 accessToken 为空表达继承，回落到项目公共账号），placeholder 提示"继承项目配置的公共账号令牌"
- 手动态：必填校验（继承态、编辑态已配置令牌且未点"修改令牌"时不校验）
- 编辑打开时按 `isInheritProjectToken` 反显类型；已配置令牌或继承类型的仓库默认锁定，需点击"修改令牌"解锁；支持"取消修改"还原到打开时的类型与状态
- 切换到"继承自项目"即视为修改（清除原令牌值），并清除残留校验错误
- 批量编辑弹窗同步支持类型选择：手动填写必填，切换继承时清空令牌值与校验状态，继承态传空由后端回落

### 保存前令牌权限检查

- 新增 `checkTokenPermission` 接口（POST `/code-repo/project-repo/check-token-permission`），录入/编辑/批量编辑保存前调用，入参与对应保存接口完全一致
- 返回 `needAlert` 时弹出"令牌权限确认"框，展示后端 `alertInfo` 文案（HTML 转义防注入、换行转 `<br>`、【xxx】关键段加粗高亮、警告图标内联首行），用户可选择"继续保存"或"取消"
- 检查接口失败不阻断保存，按正常流程继续

### 令牌信息筛选与列扩展

- 列表新增三列（均可通过列配置开关）：
  - 令牌成员角色（`tokenMemberRole`，值域随托管平台不同，完全依赖后端 filterMeta 返回）
  - 令牌角色状态（`tokenRoleStatus`，正常/异常 tag）
  - 令牌权限状态（`tokenScopeStatus`，正常/异常 tag）
- CategorySearch 新增"令牌信息"分组三项筛选：tokenMemberRoles / tokenRoleStatuses / tokenScopeStatuses，与列头 ColumnFilter 双向联动

### 平台限制统一收紧

- 代码风格自动修复：gitee/github 均不支持（radio 禁用、切换平台自动重置关闭、上次配置预填跳过、批量编辑禁选），帮助文档链接更新为新路径
- 告警抑制自动检视：gitee 不支持（同上四类处理）
- 接管 PR 管理、自动触发门禁流水线：github 不支持，切换平台重置 + 预填跳过
- 自动触发接口扫描：仅 gitcode 支持，非 gitcode 重置 + 预填跳过
- 仓库链接变化导致平台变化时，watch 统一重置受平台影响的选项，避免 disabled 状态下残留旧值

### 移除下线配置项

- 移除"禁止合并自己的 PR"（disallowSelfMerge）与"评审问题全部解决才能合并"（disallowUnresolvedDiscussionsMerge）的表单项、列表列及字段常量

### 交互细节

- 录入/编辑、批量编辑、全局配置弹窗设置 `close-on-click-modal=false`，防止点击遮罩误关闭丢失已填内容
- 全局配置按钮增加 `project_config` 权限控制（NoPermissionPopover + disabled）

## 不做什么

- 不修改后端接口实现（`check-token-permission` 由后端另行提供，前端只对接）
- 不改动项目公共账号全局配置（GlobalConfigDialog）内部逻辑，仅加防误关
- 不调整令牌轮换、同步等既有链路

## 验收标准

- [ ] 录入/编辑弹窗令牌类型可切换：继承态禁用传空，手动态必填校验生效
- [ ] 编辑已配置令牌仓库默认锁定，"修改令牌"解锁、"取消修改"还原类型与值，残留校验清除
- [ ] 批量编辑令牌类型选择生效：手动必填、继承清值清校验、提交传空
- [ ] 保存前令牌权限检查触发确认弹窗，文案格式化正确（转义/换行/高亮），取消不保存、继续正常保存，检查接口失败不阻断
- [ ] 列表新增令牌成员角色/角色状态/权限状态三列展示与筛选生效，与 CategorySearch 联动
- [ ] 平台切换时受影响开关正确重置；上次配置预填不再覆盖平台不支持项；批量编辑按选中仓库平台禁用字段
- [ ] 两个下线配置项在表单、列、字段常量中全部移除，无残留引用
- [ ] 四类弹窗点击遮罩不再误关闭；无 project_config 权限时全局配置按钮禁用并提示
