# 需求背景

## 业务场景

本轮迭代（`lt-framework` → `release_20261116`）包含四组前端改动，分别覆盖账号管理、CVE 七彩数据看板、工具箱管理软件包上传与我的流程列表展示。

## 问题痛点

1. **账号密码修改缺少校验**：编辑账号时点击"修改登陆密码"直接复用创建态密码字段，无旧密码校验、无确认密码一致性校验，容易误改他人密码且无法感知输入错误。
2. **看板合计行无法导出明细**：七彩数据看板"合计"行下载时沿用单月逻辑，`yearMonth` 为"合计"导致导出的时间区间无效，明细数据缺失。
3. **软件包上传异常态处理不完整**：分片上传接口返回非 200 时未中断流程，`btnLoading` 无法复位，页面停留在加载态；选中 0 字节文件时 `totalChunks` 为 0，循环不执行导致加载态永久不结束。
4. **我的流程缺少病毒扫描信息**：工具创建申请提交后，申请人在"我的申请"、审核人在"我的待办/我已审批"均看不到软件包病毒扫描结果、扫描任务状态与执行时间。

## 需求目标

1. 编辑账号时支持旧密码校验与确认新密码一致性校验，未修改密码时不覆盖原密码。
2. 七彩数据看板支持"合计"行按筛选年份区间导出明细。
3. 软件包上传失败或文件为空时给出明确提示并复位加载态。
4. 我的流程三个页面的"工具创建申请"表展示病毒扫描结果、任务状态、执行时间。

## 验收标准

### 功能验收

1. **账号密码修改**
   - 编辑账号点击"修改登陆密码"后展示旧密码、新密码、确认新密码三个输入项，均为必填
   - 两次输入的新密码不一致时提示"两次输入的新密码不一致"
   - 保存时未填写新密码则不提交 `password` / `oldPassword`，不会覆盖原密码
   - 提交参数不包含 `confirmPassword`
2. **七彩数据合计行导出**
   - 选择年份区间后点击合计行下载，导出时间区间为"起始年-月 ~ 结束年-月 + 1 个月"
   - 文件名格式为 `七彩数据_<起始年-月至结束年-月>_<统计类型>_统计报表`
   - 未选择年份时导出全部数据，文件名为 `七彩数据_全部<统计类型>_统计报表`
   - 非合计行导出行为与原来一致
3. **软件包上传**
   - 上传接口返回非 200 时终止上传，抛出接口 `msg`，`btnLoading` 复位为 false，文件列表回滚
   - 选择 0 字节文件时提示"文件大小不能为0，请重新选择文件！"并清空文件列表
   - 正常文件分片上传流程保持可用
4. **病毒扫描列**
   - 我的申请、我的待办、我已审批三个页面的"工具创建申请"表新增三列：病毒扫描结果、病毒扫描任务状态、病毒扫描执行时间
   - 病毒扫描结果：`success` 展示"未检出病毒"，`failed` 展示"检出病毒或扫描失败"
   - 病毒扫描任务状态：`0` 待执行、`1` 执行中、`2` 成功、`3` 失败
   - 字段为空时展示 `--`
   - 三个页面中的"社区使用"表不新增上述列

### 非功能验收

1. 不改变既有接口地址与业务主流程
2. 不引入全量重构，改动限定在上述四组功能相关文件
3. 代码通过 ESLint / Prettier / pre-commit 检查
