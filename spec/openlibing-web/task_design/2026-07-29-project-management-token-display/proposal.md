# 需求背景

## 业务场景

在项目管理模块中，用户创建公共账号时需要填写token信息。当前系统在展示token时，未能清晰地显示token对应的实际账号信息，导致用户难以识别token的归属和使用情况。此外，公共账号创建流程中，用户名字段的必填校验过于严格，影响了用户的使用体验。

## 问题痛点

1. **token展示不直观**：项目管理页面展示token信息时，缺少实际账号的明确标识，用户需要额外查询才能确认token归属
2. **公共账号创建流程繁琐**：公共账号创建时，用户名字段强制必填，某些场景下用户名并非必要信息，增加了不必要的操作成本

## 需求目标

1. 优化项目管理页面的token展示，清晰显示token对应的实际账号信息
2. 简化公共账号创建流程，去掉用户名字段的必填校验，提升用户体验

## 验收标准

### 功能验收

1. **token展示优化**
   - 项目管理页面应展示token的实际账号信息
   - 账号信息展示清晰、易读，用户无需额外查询即可识别token归属

2. **公共账号创建流程优化**
   - 公共账号创建页面，用户名字段不再强制必填
   - 用户可以选择性地填写用户名，不影响账号创建流程

### 非功能验收

1. 优化后的功能不影响现有流程的稳定性和性能
2. 代码变更符合项目编码规范，通过代码检查
