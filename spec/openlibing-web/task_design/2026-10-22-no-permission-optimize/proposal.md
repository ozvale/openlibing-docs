# 无权限提示优化

## 需求背景

无权限提示气泡（`NoPermissionPopover.vue`）是平台各操作按钮的无权限引导入口。当前存在两个体验问题：

1. 申请指引仅为纯文本描述（如「联系项目管理员添加角色，项目管理->成员管理」），用户无法一键到达申请路径，需要手动进入对应页面。
2. 气泡会展示平台（system）、组织（product）级别的角色组，这类角色与普通用户的日常权限申请无关，属于信息噪音。

## 功能描述

### 1. 申请指引链接跳转

无权限气泡中「申请指引」按角色归属级别渲染可点击链接：

- **项目级（project）**：指引文案中的「项目管理->成员管理」变为可点击链接，点击跳转 `/apps/noPermissionApply?showApply=true`（复用现有权限申请页，到达后自动弹出申请弹窗：组织/项目/角色/审核人）。
- **仓库级（repo）**：指引文案中的「代码仓管理->成员管理」变为可点击链接，点击跳转 `/apps/repos?projectId=&repoId=&showRepoUserManage=1`（代码仓管理页自动打开对应仓库的成员管理）。当前使用场景未传入 `repoId` 时，该链接降级为纯文本（无跳转目标不跳转）。
- **通用（general）**：保持纯文本「联系人工客服进行咨询」。
- 平台（system）、组织（product）：不隐藏、全部展示，其申请指引见第 2 节。

### 2. 平台/组织级别申请指引调整

无权限气泡的角色归属展示**不隐藏任何级别**（平台 system / 组织 product / 项目 project / 仓库 repo / 通用 general 全部展示）。其中：

- **平台（system）、组织（product）**：暂不开放角色申请，申请指引**整行替换**为「说明：」标签 + 说明正文「暂不开放角色申请，详情请联系人工客服进行咨询」；其中「说明：」标签与「申请指引：」标签同款深色加粗样式，正文与指引正文同款样式（无链接）。
- **通用（general）**：保持「申请指引：联系人工客服进行咨询」。
- 项目（project）、仓库（repo）：按第 1 节链接跳转。

### 3. 空态

后端 `rolesByLevel` 为空时，显示原空态文案「暂无角色配置信息，请联系项目管理员或通过服务单咨询。」（保持原逻辑与文案不变）。

### 不做

- 不改变任何权限鉴权逻辑（仅展示层优化）。
- 不改动 `permissions-meta.ts` 的介绍/指引文案。
- 不新增权限申请接口；仓库级跳转仅复用代码仓成员管理现有页面。

## 验收标准

- [ ] 项目级申请指引中「项目管理->成员管理」为可点击链接，点击跳转权限申请页并自动弹出申请弹窗
- [ ] 仓库级申请指引中「代码仓管理->成员管理」为可点击链接，点击跳转代码仓管理页并自动打开对应仓库成员管理
- [ ] 未传入 repoId 的场景下，仓库级指引降级为纯文本
- [ ] 平台/组织级别角色组不隐藏、正常展示，其申请指引整行替换为「说明：」标签 + 「暂不开放角色申请，详情请联系人工客服进行咨询」正文，标签与正文样式与申请指引一致（无链接）
- [ ] 后端 `rolesByLevel` 为空时显示原空态文案
- [ ] 新增纯函数单测通过，类型检查通过
