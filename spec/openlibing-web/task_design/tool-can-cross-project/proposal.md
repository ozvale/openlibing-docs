# tool-can-cross-project

## 需求背景

工具管理 - 工具版本在被跨项目使用时，是否需要审核的标识此前未在工具版本列表中展示，管理员无法直观查看并切换某个工具版本的跨项目审核策略。同时，工具版本列表中展示的「更新时间」字段无法准确反映版本的创建时序，需要改为「创建时间」。

## 功能描述

1. 在工具管理 - 工具版本列表（软件版本列表、访问链接版本列表）中新增列「跨项目使用该工具版本是否需审核」，字段 `canCrossProject`
2. 该列以 `el-switch` 开关形式展示，支持直接切换：
   - 开启（`'1'`）显示「需审核」，绿色
   - 关闭（`'0'`）显示「不审核」，灰色
3. 切换时弹出二次确认弹窗，确认后调用接口更新
4. 工具表单中 `canCrossProject` 字段设为必填
5. 将版本列表「更新时间」列改为「创建时间」字段 `createTime`
6. 操作列移除固定 `width: 200`，让列宽自适应

## 验收标准

- [ ] 工具版本列表新增「跨项目使用该工具版本是否需审核」列，宽度 300px
- [ ] 开关状态正确反映 `canCrossProject` 字段值（`'1'` 需审核 / `'0'` 不审核）
- [ ] 切换开关时弹出二次确认弹窗，确认后调用接口更新成功；取消则不修改
- [ ] 接口更新成功后列表自动刷新
- [ ] 工具表单 `canCrossProject` 字段未选择时校验不通过，提示「请选择」
- [ ] 版本列表「创建时间」列正确显示 `createTime` 字段值
- [ ] 操作列宽度自适应，不再固定为 200px

## 影响范围

- 模块：`openlibing-web` 仓工具管理（ToolManagement）
- 文件：4 个文件
- 接口：依赖后端 `updateToolManageItemVisitPath` 接口支持 `canCrossProject` 字段更新
- 数据：新增 `canCrossProject` 字段（`'1'`/`'0'` 字符串枚举）
