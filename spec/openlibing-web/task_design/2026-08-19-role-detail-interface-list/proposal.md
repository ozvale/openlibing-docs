# 需求背景

## 业务场景

在角色管理模块中，角色通过关联菜单获得接口访问权限。此前角色详情（查看模式）仅能查看角色关联的菜单树，无法直观看到角色实际授权的接口 URL 范围。用户在核对角色权限、排查越权/授权不足问题时，需要逐个展开菜单核对，效率低且容易遗漏。

## 问题痛点

1. **授权范围不可见**：角色详情只有菜单维度的展示，缺少接口 URL 维度的直观视图，用户难以快速回答"这个角色到底能访问哪些接口"
2. **排查效率低**：权限问题排查需要人工对照菜单与接口的映射关系，缺少可检索、可分页的接口清单

## 需求目标

在角色详情查看模式下新增「接口列表」面板：

1. 分页展示角色关联的菜单接口 URL（表格列：模块名称、接口地址）
2. 支持按接口地址模糊搜索过滤
3. 仅查看模式展示，不影响新增/编辑模式

## 验收标准

### 功能验收

1. **接口列表面板**
   - 角色详情弹窗（查看模式）展示「接口列表」面板，包含搜索框 + 表格 + 分页
   - 表格列：模块名称（menuName）、接口地址（menuUrl，超长省略 + tooltip）
   - 空数据展示 Empty 组件

2. **搜索与分页**
   - 接口地址输入框支持模糊查询，回车/失焦触发，可清空
   - 分页支持 10/20/50/100 每页条数切换与页码切换
   - 查询条件变化时重置到第一页

3. **模式约束**
   - 新增/编辑角色模式下不显示该面板

### 非功能验收

1. 不影响现有角色管理功能（增删改查、菜单权限配置）
2. 代码变更符合项目编码规范
