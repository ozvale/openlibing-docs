# 2026-06 代码检查页面告警代码片段与实际代码不一致 提案

## 1. 需求背景

代码检查页面告警详情中展示的代码片段与实际源代码不一致，影响开发者对告警位置的判断。

### 问题描述

- 告警代码片段中多个连续空格在浏览器渲染时被合并为单个空格
- 导致缩进丢失，代码片段与实际源代码存在视觉差异
- 开发者难以准确定位告警行中的问题位置

## 2. 验收标准

### 功能验收

- [x] 告警代码片段完整保留源代码中的空格和缩进
- [x] 代码片段展示与实际源代码一致

### 测试验收

- [x] 验证含多个连续空格的代码行展示正确
- [ ] 验证长行代码自动换行显示正常

## 3. 变更范围

### 涉及模块

- **前端组件**: `apps/web-openlibing/src/views/CodeCheckDashboard/CodeLine.vue`

### 变更类型

- Bug 修复（代码片段空格显示不一致）

## 4. 风险评估

- **风险等级**: 低
- **影响范围**: 仅涉及代码检查告警详情的代码片段展示样式
- **破坏性变更**: 无
