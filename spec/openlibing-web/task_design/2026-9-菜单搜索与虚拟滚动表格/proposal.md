# Proposal: 菜单管理页签节点搜索与 el-table-v2 虚拟滚动

## 需求背景

权限管理-菜单管理页签使用原生树形表格全量渲染 DOM，菜单数量多时页面明显卡顿；同时缺少节点搜索能力，用户在深层级菜单树中定位某个节点需要逐级展开查找，效率低。

## 需求描述

1. 菜单页签工具栏新增节点搜索下拉（可过滤），选项平铺全树并带祖先路径标识
2. 选中节点后自动展开其祖先链、高亮该行并滚动至可视区；清空选择还原搜索前的展开状态
3. 表格迁移到 el-table-v2 虚拟滚动，仅渲染可视区行，消除大数据量卡顿
4. 表格样式对齐接口列表（.table-common）：表头灰底、只有横向分隔线、无竖线/外框
5. 表格填满容器宽度：无右侧空白、横线通到右缘、表头背景满宽
6. 增删改后仅刷新表格数据，保留当前展开/搜索状态，不重新触发搜索定位

## 验收标准

- [x] 搜索下拉可按节点名或路径关键字过滤，选项 label 带祖先路径可区分同名节点
- [x] 选中节点后祖先链自动展开、目标行高亮并滚动至可视区居中
- [x] 清空选择后还原搜索前的展开快照
- [x] 大数据量下滚动流畅，仅可视区行参与渲染（虚拟滚动）
- [x] 表格样式与接口列表一致：表头灰底 #f4f6fa、只有横线、无竖线/外框
- [x] 表格填满容器：右侧无空白、横线通到右缘、表头背景满宽
- [x] 刷新页面后展开状态不丢失（与最新树求交集过滤悬空 id）
- [x] 增删改成功后表格数据刷新，展开/搜索状态保持不变
