# 【openlibing-web】SBOM 成分分析筛选移入表头并支持排序 — 需求提案

## 需求背景

gamma 环境「SBOM - 软件成分查询」页面（`/apps/sbomManage`，组件
`apps/web-openlibing/src/views/SbomManagement/CompositionAnalysis/index.vue`）
当前查询条件集中在列表上方的 `search-filters` 区域（License / License数量 /
License合规性 / 漏洞级别筛选 / 依赖类型 / 精准查询 / package搜索 / 合并展示），
占用版面且与所作用的数据列缺乏直观关联；列表本身不支持排序。

用户希望：

1. 查询条件移到**列表表头**：点击表头漏斗图标弹出筛选面板，筛选生效后图标高亮；
2. 表头支持**升降序排序**；
3. 复杂筛选条件（多选下拉、包含/排除三态、输入框+开关组合）交互语义保持不变。

## 需求范围（用户已确认的决策）

| 决策点               | 结论                                                                                                                            |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 排序列范围           | 软件包名称、依赖类型、漏洞风险数值、License数量、License合规性（后两者归 License 表头），以现有条件为主；**版本列不筛选不排序** |
| 漏洞风险数值排序口径 | 按指定级别排序（致命/高危/中危/低危/无风险/未知），复用 `common.ts#sortFieldList`                                               |
| 合并展示开关         | 移入「软件包名称」列表头筛选面板（与 package 输入框、精准查询开关同面板）                                                       |

## 表头分布设计（用户确认版）

| 表头         | 面板内容                                                                                              |
| ------------ | ----------------------------------------------------------------------------------------------------- |
| 软件包名称   | package名称输入框 + 精准查询开关 + 合并展示开关                                                       |
| 依赖类型     | 依赖类型多选（直接/间接/直接与间接）                                                                  |
| 漏洞风险数值 | 漏洞级别包含/排除筛选 + 排序级别选择（6 级 + 升降序）                                                 |
| License      | License 多选 + License数量多选 + License合规性单选 + 排序选择（License数量 / License合规性 + 升降序） |
| 版本         | 无筛选无排序                                                                                          |

工具栏仅保留：漏洞依赖刷新、全量导出。原 `search-filters` 筛选区整体移除。

## 验收标准

1. 表头漏斗图标点击弹出对应筛选面板；有筛选值时图标高亮；清空后恢复灰色。
2. 各筛选条件查询行为与改造前一致（多选防抖、变更回第 1 页、漏洞数量汇总刷新、合并展示切换重置页码）。
3. 排序：软件包名称、依赖类型列出现标准升降序 caret；漏洞风险数值、License 列通过面板内排序选择器指定字段与方向，表头出现排序方向指示；再次取消排序恢复默认（按 name、`.` 开头包名靠后）。
4. 排序请求走服务端（`querySbomPackagesMultiFilter` 新增 `sortField`/`sortDir`），分页正确；合并展示（分组模式）下排序按组聚合值生效。
5. 不传排序字段时，后端行为与现状完全一致（兼容旧调用方）。
6. 漏洞依赖刷新、全量导出、制品信息表单、漏洞详情弹窗等功能不受影响；导出弹窗 `queryInfo` 传参不变。
