# Proposal: 管理中心左侧菜单支持折叠与右侧自适应

## 需求背景

管理中心页面（`manageCenter/index.vue`）左侧菜单固定宽度 200px，无法折叠收起。当用户在右侧内容区查看宽表格、看板等数据时，左侧菜单占用较多横向空间，影响内容展示效率。需要支持菜单折叠/展开，折叠后右侧内容区自适应撑满剩余宽度。

## 需求描述

为管理中心左侧菜单增加折叠/展开能力：

1. 左侧菜单可通过底部按钮在「展开（200px）」与「折叠（64px 图标条）」两种状态间切换
2. 折叠状态下复用 Element Plus `el-menu` 原生 `collapse` 能力，子菜单以弹出形式展示
3. 右侧内容区宽度自适应：菜单展开时占剩余宽度，菜单折叠时自动撑满
4. 折叠/展开过渡平滑，不影响已有菜单选中、路由跳转等行为

## 验收标准

- [ ] 左侧菜单底部存在折叠/展开按钮，含图标（Fold/Expand）与文案
- [ ] 点击按钮可在展开 ↔ 折叠状态切换，状态由 `isCollapse` 控制
- [ ] 展开态：左侧宽度 200px，菜单文字与图标正常展示
- [ ] 折叠态：左侧宽度 64px，仅展示图标，子菜单以弹出形式展开
- [ ] 右侧内容区使用 `flex: 1` 自适应宽度，菜单折叠/展开时无横向溢出
- [ ] 折叠/展开过渡有平滑动画（width transition）
- [ ] 已有的菜单选中态（defaultName）、`menuSelect` 路由跳转、权限控制（menuShow / opsShow / aiManageShow / aiConfigShow）行为不受影响
- [ ] 不引入新的依赖（复用已存在的 `@element-plus/icons-vue`）

## 影响范围

| 文件                                                   | 变更类型 | 说明                                                                                                              |
| ------------------------------------------------------ | -------- | ----------------------------------------------------------------------------------------------------------------- |
| `apps/web-openlibing/src/views/manageCenter/index.vue` | 功能新增 | 模板增加折叠按钮与 collapse 绑定；script 增加 isCollapse 状态与 toggleCollapse；样式改为 flex 自适应 + 折叠态样式 |

单文件、纯前端 UI 改动，无接口/数据模型/鉴权变化。

## 模式判定

Light 模式：单仓单文件、约 85 行改动、无接口与数据模型变化、无安全影响、最小验证。
