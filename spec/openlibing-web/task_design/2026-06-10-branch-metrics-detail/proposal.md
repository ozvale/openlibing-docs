# 2026-06-10 分支管理代码质量指标详情提案

## 1. 需求背景

在仓库管理的分支列表页面中，已展示代码规模、平均代码行数、平均圈复杂度、总代码重复率、总文件重复率等 5 个代码质量指标。当前这些指标仅展示数值，用户无法查看指标对应的文件级明细数据。需要新增指标详情功能，支持用户点击指标值查看该指标下各文件的详细数据，并支持通过 URL 参数直接跳转到指定仓库的指标详情页面。

### 问题描述

- 代码质量指标仅展示汇总值，无法下钻到文件级别
- 无文件名称模糊搜索能力
- 数值列无排序能力
- 总文件重复率的重复文件字段为数组，需要合并单元格展示
- 外部系统需要通过 URL 直接跳转到指定仓库的指标详情

## 2. 验收标准

### 功能验收

- [x] 点击分支列表中 5 个指标值可打开指标详情弹窗
- [x] 弹窗标题根据 metricType 动态显示（代码规模详情/平均代码行数详情/平均圈复杂度详情/总代码重复率详情/总文件重复率详情）
- [x] 弹窗展示代码仓名称、分支名称、流水线链接
- [x] 流水线链接使用 goToNotice 安全跳转
- [x] 文件名称列支持模糊搜索筛选
- [x] 数值列支持自定义排序（升序/降序）
- [x] 总文件重复率（metricType=4）的重复文件字段为数组时，合并单元格展示
- [x] 序号列在合并单元格场景下按原始行号显示
- [x] 支持 URL 参数（repoId、branchName、pipelineRunId、metricType）自动打开指标详情
- [x] 从指标详情返回分支管理时清除 URL 参数

### 代码质量验收

- [x] 代码格式符合 ESLint 规范
- [x] 组件职责清晰：MetricsDetailDialog 为纯内容组件，el-dialog 外壳由父组件控制
- [x] 列配置公共部分（文件名称列）提取为常量复用
