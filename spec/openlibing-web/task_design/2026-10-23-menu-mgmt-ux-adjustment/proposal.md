# Proposal: 菜单管理易用性调整（表头筛选 + 菜单定位面板）

## 需求背景

菜单管理页（`src/views/authorityManagement/menu.vue`）存在两处易用性问题：

1. **接口列表页签**（`components/InterfaceListTab.vue`）：「请求方式」（httpMethod）「接口用途/类型」（urlFlag）两列均无表头筛选——接口用途/类型的筛选藏在表格上方工具栏下拉中，与项目既有表头漏斗筛选范式（Repos 页面 ColumnFilter）不一致；「同步」按钮的二次确认用的是 `$confirm`（ElMessageBox），违反项目规范（所有二次确认弹窗必须使用公共 ConfirmDialog 组件）。
2. **菜单页签**：「搜索并选择节点」入口为表格上方 680px 宽的大号下拉（el-select-v2），占用工具栏大量空间且与「名称」列强相关的定位操作割裂。UX 要求将入口迁到「名称」表头上，选择菜单位置以弹窗形式展现。

UX 设计稿：`https://moonvy.com/project/2801b8be-c42a-490b-8fdb-434c8561d40b/55bd0657-ac8a-48e9-ab92-b5eada1cd820`（需登录暂无法直接访问，本 spec 按项目既有范式与合理默认撰写，弹窗细节标注 TBD 待设计稿补充）。

## 功能描述

### 1. 接口列表页签：两列表头筛选（均为单选）

- 「请求方式」列表头增加筛选，单选（GET/POST/PUT/DELETE 等），确认后列表按所选方式过滤
- 「接口用途/类型」列表头增加筛选，单选（未配置接口/人机接口/机机接口/服务内接口），**替代**工具栏中的类型下拉（工具栏保留 URL 输入框与同步按钮）
- 筛选变更即查（重置第 1 页）；清空/重置恢复全量；两列筛选可与 URL 筛选叠加生效

### 2. 接口列表页签：同步数据二次弹窗按规范改造

- 「同步」点击后的二次确认从 `$confirm`（ElMessageBox）改为公共 `confirmDialog.warning`，弹窗样式/按钮与项目规范一致

### 3. 菜单页签：定位入口迁移到「名称」表头（2026-10-26 按 UX 稿定稿为 popover 级联面板）

- 移除工具栏 680px 的「搜索并选择节点」下拉（保留「新增」按钮）
- 「名称」表头变为：名称文字 + 漏斗图标；点击图标在图标下方弹出 **popover 多列级联定位面板**（MenuLocatorPanel，宽 900）——列头「N级菜单」、点击节点逐级展开下一列、面包屑展示已选路径、底部「清除定位 / 取消 / 定位到此菜单」操作区
- 面板内搜索（2026-10-27）：搜索框平铺全量节点（label 带祖先路径），选中后**仅高亮面板内祖先链，不直接定位**，需手动点「定位到此菜单」确认
- 定位逻辑（展开祖先链、高亮选中行、滚动居中、清空还原展开快照）复用现有实现不变
- 已定位节点时表头漏斗图标呈激活态

### 4. 菜单页签视觉调整与附带整改（2026-10-26 ~ 10-27 新增，详见 design.md §3/§4）

- 「未匹配接口列表」「人工配置接口」两页签隐藏
- 名称列展开/收起图标改方框 +/-；树形缩进 24px 网格对齐（子级方框与父级文字左对齐）
- 行状态色：定位行 #FFB85C > 点选行 #E6F6FF > hover #F1F7FE
- 菜单删除二次弹窗迁移公共 `confirmDialog.danger`（「确认删除 / 确定要删除该条数据吗？」）
- 新增菜单/访问白名单 URL 输入提交前 trim，勿流入接口参数

### 5. 访问白名单接口页签：表头筛选与字段提示（2026-10-28 新增，详见 design.md §5）

- 「请求方式」列表头增加筛选（GET/POST/PUT/DELETE，与接口列表页签一致）
- 「是否豁免登录白名单」「是否无用户信息白名单」「是否无认证访问白名单」三列表头各增加筛选（全部/是/否）与问号提示（气泡仅落在问号图标上，表头文字 hover 不触发）：
  - 豁免登录：无登录凭证的相关接口
  - 无用户信息：无法获取到openlibing用户信息的接口
  - 无认证访问：无需token校验就能访问的接口，可能有登录凭证、可能无登录凭证的接口
- 筛选即查（重置第 1 页），与 URL 输入筛选叠加生效；选「全部」恢复全量
- 新增/修改弹窗：三个白名单表单项 label 旁增加同文案问号提示；「请求方式」下拉补齐 GET/POST/PUT/DELETE（原仅 GET/POST）
- 菜单页签 URL 配置「请求方式」下拉同步补齐 GET/POST/PUT/DELETE
