# 工具管理模块功能增强需求提案

## 需求背景

为完善工具管理模块功能，提升平台工具治理能力和安全性，需要实现以下功能：

1. **工具与标签绑定**：当前工具管理缺少标签分类能力，无法为工具设置多个标签进行分类管理。
2. **工具与项目空间绑定**：工具缺少与项目空间的关联机制，无法实现工具与项目空间的绑定关系管理。
3. **一键举报机制**：缺少工具举报功能，用户无法对违规工具进行举报反馈，平台治理能力不足。
4. **安全提示内容补充**：工具上传、审核、下载环节缺少安全提示，存在潜在安全风险。

## 关联 Issue

- 主 Issue: openlibing/openlibing-framework#46

## 验收标准

### 1. 工具与标签绑定

- [ ] 支持为工具配置多个标签
- [ ] 提供标签绑定界面，支持选择、添加、删除标签
- [ ] 标签绑定数据正确保存并可在工具详情中显示
- [ ] 支持通过标签筛选工具列表

### 2. 工具与项目空间绑定

- [ ] 支持工具与项目空间建立绑定关系
- [ ] 提供绑定操作界面（选择项目空间、确认绑定）
- [ ] 绑定关系正确保存并可查看管理
- [ ] 支持解除绑定关系

### 3. 一键举报机制

- [ ] 工具详情页提供举报入口（一键举报按钮）
- [ ] 待办中心新增举报工具模块：
  - 举报申请页面（ToolReportApplication）
  - 举报审核页面（ToolReportReview）
  - 举报历史记录页面（ToolReportReviewHistory）
- [ ] 举报申请流程完整（提交举报、填写举报原因）
- [ ] 举报审核流程完整（审核员查看举报、审核处理）
- [ ] 举报历史记录可查看

### 4. 安全提示内容

- [ ] 工具上传：上传前显示安全提示确认弹窗
  - 明确禁止上传内容（破解软件、盗版软件、病毒、恶意代码、违法内容等）
  - 说明违规后果（下架、禁用账号等）
- [ ] 工具审核：审核弹窗显示审核职责提示
  - 明确审核职责（核实合法性、检查恶意代码、确认无侵权等）
  - 提示审核员谨慎审核
- [ ] 工具下载：下载前显示安全提示
  - 显示上传者信息（用户ID、用户名）
  - 提示下载者自行确认安全（杀毒扫描、验证来源、谨慎运行等）
  - 说明平台免责声明

### 5. 审核日志查看

- [ ] 支持查看工具审核日志历史
- [ ] 显示审核操作记录（审核时间、审核人、审核结果等）

## 非功能性需求

- 所有功能需兼容现有工具管理模块架构
- UI 设计符合平台现有风格
- 安全提示内容准确、明确、易理解
- 举报流程简洁高效

## 影响范围

- 前端模块：工具管理（MyTool、ToolManage、ToolMarket）
- 前端模块：待办中心（新增举报工具子模块）
- 后端接口：新增标签绑定、项目空间绑定、举报相关 API
