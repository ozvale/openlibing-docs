# 2026-08-21-role-menu-tree-search

## 需求
角色管理（新增/编辑/查看角色弹窗）中的权限菜单树数据量大，查找某个菜单节点困难。在树上方增加搜索框：输入关键字自动联想匹配菜单；选中后树定位到该节点——展开父级、高亮当前节点、树容器滚动到该节点可见位置。

## 影响范围
- `openlibing-web/apps/web-openlibing/src/views/authorityManagement/role.vue`（单文件，纯前端 UI 交互）

## 验收标准
- [ ] 树上方显示搜索框，输入关键字后联想列表展示匹配菜单（含 `父级 / 子级` 完整路径），支持清空
- [ ] 空关键字或仅聚焦时不弹出联想列表
- [ ] 选中联想项后：目标节点的父级链自动展开、当前节点高亮（项目主色）、树容器滚动使节点居中可见
- [ ] 滚动仅作用于树容器本身，不连带滚动外层弹窗
