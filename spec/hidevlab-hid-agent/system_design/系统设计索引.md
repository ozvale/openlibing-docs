# hidevlab-hid-agent 系统设计索引

本目录用于沉淀 `hidevlab-hid-agent` 的系统级设计。HiD-Agent 是部署在服务器/工作站（含华为 Ascend NPU 服务器、Kunpeng 服务器、BMS 裸金属、FusionCompute 虚拟机）上的轻量级数据采集与运维代理，负责定时采集系统指标并 HTTPS 上报 HiDevLab 后端，同时提供被后端远程调用的控制面接口（配置下发、软件预制、agent/网络配置删除）。Agent 为端侧无状态进程，无 DB/MQ/Redis。

## 模块架构

- **入口/路由层（main.go）**: HTTP 路由与 handler
  - `setConfig`: 配置查询/增量更新
  - `handleSoftwareInstall/Uninstall/Check`: 软件预制
  - `handleAgentDelete`: agent 自卸载
  - `handleNetConfigDelete`: 网络配置清理

- **业务层（service/）**:
  - `config.go`: `AgentConfig`/`MetricsConfig`、`Load`/`Save`/`Export`
  - `collect.go`: 指标采集与上报、上报线程池
  - `token.go`: `TokenCache`、token 加载/获取/加密存储
  - `software.go`: 软件预制安装/卸载/检查
  - `delete.go`: agent 自卸载与网络配置清理

- **工具层（tools/）**:
  - `encryptor.go`: 三段式 AES-GCM 加密
  - `signature.go`: HMAC-SHA256 签名校验
  - `cert.go`: 自签名证书生成
  - `systemutils.go`: 系统命令封装
  - `log.go`: zap 日志

- **常量层（constant/const.go）**: 版本、端口、路径、`IP_TO_REGION`、`REGION_TO_*` 路由映射表
