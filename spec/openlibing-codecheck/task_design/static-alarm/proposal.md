# 版本级别（nightly）流水线支持开源代码检测工具结果可视，并能采集数据支撑运营

## 需求背景

在 DevOps 平台中，Nightly 版本级别流水线已集成 CodeQL 等开源代码检测工具进行静态扫描，但扫描结果以 SARIF 文件形式存储在 OBS 上，缺乏可视化展示和数据运营支撑能力。开发人员无法直观查看静态告警问题，也无法按仓库、分支、状态等维度进行筛选和统计，导致静态扫描结果难以被有效消费和跟踪。

本需求旨在实现 SARIF 扫描结果的自动解析、入库和可视化查询，为开发团队提供静态告警的全生命周期管理能力（查看、筛选、屏蔽），并为运营提供数据支撑。

## 验收标准

- [x] cicd 仓库在构建产物分析完成后，自动检测 SARIF 文件并触发 codecheck 侧的异步解析
- [x] codecheck 仓库接收 SARIF 扫描结果，通过 RabbitMQ 异步解析入库
- [x] 支持 CodeQL SARIF 格式的解析（可扩展其他工具）
- [x] 问题入库采用指纹去重机制（SHA-256: tool|ruleId|filePath|locationHashRaw），同一问题不重复创建
- [x] 支持问题状态自动流转：OPEN（新增/再次出现）→ RESOLVED（消失）
- [x] 提供分页查询静态告警问题列表接口
- [x] 提供查询各状态问题数量接口
- [x] 提供查询单条问题完整详情接口
- [x] 提供获取筛选项接口（支持级联筛选）
- [x] 提供仓库自动补全搜索接口
- [x] 提供批量屏蔽问题接口
- [x] MongoDB 索引优化，支持高效查询
- [x] RabbitMQ 死信队列配置，2 小时 TTL，防止消息积压
