### 1.2 需求摘要

详见 `测试过程数据/需求分析文档.md`：1.6 功能点 `FP-01~FP-08`、1.7 业务规则 `BR-01~BR-12`、1.8 异常边界 `EX-01~EX-09`。

简述：执行历史 Tab 以 sessionStorage 条件快照实现筛选条件与页码的临时恢复；外链 status 参数优先；owner 归属校验防跨账号串用；所有存储读写静默降级；手动查询仍重置页码。

### 1.3 测试目标

1. 验证 6 条验收标准全部成立（条件与页码恢复、外链优先、刷新恢复/关闭清除、跨账号隔离、异常降级、手动查询重置页码）。
2. 验证恢复范围覆盖日度范围、状态多选、Merge ID、页码、页大小、排序六类条件。
3. 验证恢复不影响既有功能：日期筛选默认值、查看详情弹窗、分页、列头筛选。

### 1.4 测试范围

| 测试类型 | 是否覆盖 | 说明 |
|----------|----------|------|
| UI功能测试 | 是 | 主维度。覆盖 FP-01~FP-08、BR-01~BR-12、EX-01~EX-09；以 BETA 真实页面操作 + sessionStorage 断言双通道取证 |
| API接口测试 | 否 | 查询接口入参出参零变化（design 6 章明确不适用）；接口层回归由既有 `02_API测试/构建管理/流水线/流水线执行历史查询参数校验` 承担 |

| 安全测试 | 是（限定） | 6 维度：① 认证校验 不覆盖（本次不改认证）；② 横向越权 **覆盖**（EX-04 跨账号缓存串用，属前端数据越权面）；③ 纵向越权 不覆盖（无角色面变更）；④ 传输安全 不覆盖（不改传输）；⑤ CSRF 不覆盖（无状态变更请求）；⑥ 敏感信息防护 **覆盖**（快照不含凭证/token，仅查询条件） |

> 维度组合定稿（v3.23，AI 按推荐定稿）：**UI 为主 + 安全限定维度（跨账号隔离、敏感信息）**。
> 备选与权衡：A「仅 UI」遗漏跨账号与敏感信息两个安全面，而 owner 校验正是本需求的安全设计点；B「UI+API+安全全量」中 API/传输/CSRF 与本次改动无交集，徒增噪声；推荐 A'（UI 为主 + 安全限定两维度）。

### 1.5 测试策略

- 手工测试：跨账号隔离（双账号切换）、标签页关闭清除、隐私模式降级等难以稳定自动化的场景，作为手工补充项记录。
- 自动化测试：Playwright UI 脚本覆盖主链路（切 Tab 恢复、外链优先、刷新恢复、手动查询重置页码、页大小与排序恢复、异常快照降级），并以 `sessionStorage.getItem` 直接断言快照结构（owner + 各字段）；脚本位置 `src/automation/software-cicd/ui/build_management/pipeline/beta/`。
- 存量回归：日期筛选默认值、查看详情弹窗、分页翻页、状态/Merge ID 列头筛选。
- 优先级：P0 = 切 Tab 恢复（条件+页码）、外链 status 优先、跨账号隔离、手动查询重置页码；P1 = 刷新恢复、页大小恢复、排序恢复、异常降级、仅条件不恢复数据；P2 = 标签页关闭清除、敏感信息检查、存量回归抽检。

### 1.7 风险与约束

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| master 未合入实现，BETA 环境版本与最终代码可能不一致 | 断言与实际发布版本不符 | 执行前记录部署版本标识；以 BETA 实测行为为准，报告注明"基于 BETA 已部署版本" |
| sessionStorage 为标签页级，Playwright 同一 context 多 page 的隔离需确认 | 恢复类断言不稳定 | 每用例新 page、复用同一 context（同标签页语义）；跨用例清理快照键，避免互相污染 |
| 执行历史数据量大（实测 716 条）且持续轮询 | 等待不稳定、翻页断言易抖动 | 断言使用等待+轮询；不依赖具体行内容，只用页码/条件值 |
| 列头筛选/日期选择器为 DevUI/Element Plus 自定义组件，定位复杂 | 自动化不稳定 | 优先用 `table-header-filter` 容器定位；日期通过快照注入而非 UI 逐日点选（保持"恢复"断言聚焦） |
| 第二账号权限不确定 | 跨账号用例可能阻塞 | 执行前确认 P-01；不可得则改为"伪造 owner 写快照"构造，结论注明构造方式 |
| 隐私模式无法在 Playwright 中真实模拟 | EX-01 覆盖不足 | 用"写入超长/异常值使 setItem 抛错"或直接替换 sessionStorage 方法模拟异常，断言主流程不中断 |
