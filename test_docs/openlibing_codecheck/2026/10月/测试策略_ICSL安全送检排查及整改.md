## 3. 专项验证设计和执行详情

### 3.1 测试设计范式

1. **两层结构**：12 条模式级用例（TC-ISSUE372-001 至 012）+ 按仓实例化用例（预留 TC-ISSUE372-101 至 1xx）。
2. **负向 + 正向配对**：每条问题先验证原攻击载荷被拒绝，再验证合法业务行为与整改前一致。
3. **聚合判定**：每条模式级用例的覆盖对象为 `执行记录跟踪表.xlsx` 对应明细 sheet；fail > block > skip > pass，计入项全部通过才判通过。
4. **不计入口径**：open 未修复、定性误报的 issue 标「不计入」，不进入分母。
5. **影响面推导**：changed file → 接口/页面/Action 入口；changed symbol → 调用方；changed config → 部署形态。
6. **证据固定三件套**：请求/响应或页面截图、服务端日志、复扫报告（如有），登记到明细 sheet 的「实际结果与证据」列。

### 3.2 专项验证设计（按变更类型）

**1.TC-ISSUE372-001 认证鉴权与越权整改验证（P0）**:

- 测试步骤: 以匿名、低权、跨租户三类身份访问原问题接口；再以合法用户执行正常链路
- 预期结果: 三类身份均被拒绝（401/403 或业务拒绝）、无数据泄露；合法用户功能正常

**2.TC-ISSUE372-002 敏感数据与凭证治理验证（P0）**:

- 测试步骤: 检查配置、镜像、日志、响应、前端产物中的凭证与敏感数据
- 预期结果: 均无明文凭证与敏感数据

**3.TC-ISSUE372-003 输入校验与注入防护验证（P1）**:

- 测试步骤: 构造 SQL/日志注入、XSS、反序列化 payload
- 预期结果: 被拒绝或转义，不产生注入效果

**4.TC-ISSUE372-004 SSRF与外连安全验证（P0）**:

- 测试步骤: 构造内网地址、file 协议、跳转内网、非白名单域名请求
- 预期结果: 均被拒绝，服务端未发出请求

**5.TC-ISSUE372-005 路径穿越与文件处理验证（P1）**:

- 测试步骤: 构造路径穿越、ZipSlip、超限上传/下载
- 预期结果: 防护生效，无法越界读写

**6.TC-ISSUE372-006 命令注入与不可信执行验证（P0）**:

- 测试步骤: 构造 shell 拼接参数与 PR 代码执行场景
- 预期结果: 不执行任意命令；PR 代码不在宿主执行

**7.TC-ISSUE372-007 传输与Web安全基线验证（P1）**:

- 测试步骤: 检查响应头、HTTPS、CSRF、Cookie、证书校验
- 预期结果: 符合安全基线

**8.TC-ISSUE372-008 弱算法与签名重放验证（P1）**:

- 测试步骤: 检查签名算法与重放防护
- 预期结果: 弱算法已整改；含时间戳与防重放，重放请求被拒绝

**9.TC-ISSUE372-009 拒绝服务与资源滥用验证（P1）**:

- 测试步骤: 构造超大 `pageSize`、ReDoS、大文件/大内存请求
- 预期结果: 有限制、不引发资源滥用

**10.TC-ISSUE372-010 供应链与完整性验证（P1）**:

- 测试步骤: 复扫依赖 CVE；检查下载校验与 Action 权限
- 预期结果: 原 CVE 不再命中、无新增高危；下载有校验；Action 权限最小化

**11.TC-ISSUE372-011 暴露面与安全配置验证（P1）**:

- 测试步骤: 探测 swagger/actuator/废弃接口/产物残留
- 预期结果: 暴露面收敛、废弃接口下线、产物残留清理

**12.TC-ISSUE372-012 审计与错误处理验证（P2）**:

- 测试步骤: 检查关键操作审计与异常返回
- 预期结果: 审计完备；异常不返回原文、无日志注入

## 4. 测试范围

### 4.1 纳入范围

- closed 且已合入修复的 issue（标注「已修复」）
- open 但修复 PR 已提交、提测后的问题（转「已修复」后纳入）
- 12 类变更类型对应的明细 sheet 全部问题
- 跨仓公共组件、网关级配置、Action workflow 权限等放大效应明显的改动

### 4.2 不纳入范围

- open 未修复问题（仅登记，不判定）
- 定性为误报或已缓解、无代码变更的报告型 issue（记录结论，不做回归）
- 非安全类需求与 bug（已排除 7 条）
- 依赖扫描工具自身检出能力与规则库（以复扫报告为准）
- 生产环境渗透测试与真实凭证操作
