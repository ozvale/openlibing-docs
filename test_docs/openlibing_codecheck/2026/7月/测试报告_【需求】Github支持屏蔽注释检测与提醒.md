* 2.输入github仓库地址（如https://github.com/xxx/yyy）
* 3.提交录入请求
* 4.验证仓库是否成功录入openlibing代码仓管理
* 5.检查仓库详情页，确认分支信息已自动同步
* 6.验证仓库基本信息（名称、描述、默认分支）与github一致
* 预期结果:
* github仓库成功录入openlibing代码仓管理，分支信息自动同步且与github一致

* 测试步骤:
* 1.在openlibing代码仓管理页面为该github仓库配置有权限的github令牌
* 2.保存令牌配置
* 3.验证openlibing是否调用github API在仓库中创建webhook
* 4.登录github仓库的Settings > Webhooks页面，确认webhook已创建
* 5.检查webhook的Payload URL、Content type、Events配置是否正确
* 预期结果:
* 配置有权限令牌后，openlibing自动在github仓库创建webhook，webhook配置正确

**3. 通过openlibing在github创建webhook成功后，开启告警抑制自动检视开关，在github仓开启pr自动检视代码中的告警抑制注释**:
* 前置条件:github仓库已录入，webhook已创建

* 5.查看github PR评论，验证是否收到告警抑制注释检视意见

* 预期结果:
