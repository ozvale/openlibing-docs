### 3.1 功能测试专项

**1. 多维度单选/多选筛选测试（平台/可见性/用途/语言/状态/是否接管PR/自动触发/开源类型/WebHook状态）**:
* 前置条件:代码仓管理页面已加载，存在多个维度不同属性的代码仓数据
* 测试步骤:
* 1.进入代码仓管理页面
* 2.【代码仓平台】单选筛选：选择Gitee，验证筛选结果代码仓均为Gitee平台
* 3.【代码仓平台】多选筛选：同时选择Gitee+GitCode，验证筛选结果包含两个平台的代码仓
* 4.【可见性】单选筛选：选择私有，验证筛选结果代码仓均为私有可见性
* 5.【可见性】多选筛选：同时选择私有+内部，验证筛选结果包含两种可见性的代码仓
* 6.【用途】单选筛选：选择"CI/CD流水线"，验证筛选结果代码仓用途匹配
* 7.【用途】多选筛选：同时选择两个用途类型，验证筛选结果包含对应用途的代码仓
* 8.【语言】单选筛选：选择Java，验证筛选结果代码仓语言均为Java
* 9.【语言】多选筛选：同时选择Java+Python，验证筛选结果包含两种语言的代码仓
* 10.【状态】单选筛选：选择"正常"，验证筛选结果代码仓状态均为正常
* 11.【状态】多选筛选：同时选择正常+异常，验证筛选结果包含两种状态的代码仓
* 12.【是否接管PR】单选筛选：选择"是"，验证筛选结果代码仓均已接管PR
* 13.【自动触发】单选筛选：选择"是"，验证筛选结果代码仓均开启自动触发
* 14.【开源类型】单选筛选：选择对应类型，验证筛选结果代码仓开源类型匹配
* 15.【开源类型】多选筛选：同时选择多个开源类型，验证筛选结果对应
* 16.【WebHook状态】单选筛选：选择"已配置"，验证筛选结果代码仓WebHook均已配置
* 17.【WebHook状态】多选筛选：同时选择已配置+未配置，验证筛选结果包含两种状态的代码仓
* 预期结果:
* 各维度单选/多选筛选结果准确，符合所选条件的代码仓正确展示

**2. 语言为空的代码仓筛选测试**:
* 前置条件:存在语言字段为空（未设置/未识别）的代码仓数据
* 测试步骤:
* 1.进入代码仓管理页面
* 2.在语言筛选条件中选择"未设置"或空值选项
* 3.验证筛选结果是否仅包含语言为空的代码仓
* 4.将筛选切换为某个具体语言，验证结果不包含语言为空的代码仓
* 5.同时选择"未设置"和某个具体语言，验证结果包含语言为空和该语言的代码仓
* 预期结果:
* 语言为空的代码仓筛选准确，"未设置"选项能正确筛选出语言为空的代码仓

**3. 多条件组合筛选测试**:
* 前置条件:存在丰富多样的代码仓数据，满足多维度组合条件
* 测试步骤:
* 1.选择【代码仓平台】= GitCode + 【状态】= 正常，验证结果同时满足两个条件
* 2.选择【语言】= Java + 【可见性】= 私有，验证结果同时满足两个条件
* 3.选择【是否接管PR】= 是 + 【自动触发】= 是，验证结果同时满足两个条件
* 4.选择【平台】多选（Gitee+GitCode）+ 【用途】单选 + 【WebHook状态】单选，验证三条件组合筛选正确
* 5.选择全维度各选一个条件，验证多条件组合筛选结果正确
* 预期结果:
* 多条件组合筛选结果准确，同时满足所有已选筛选条件

**4. 筛选条件重置/清空功能测试**:
* 前置条件:已设置若干筛选条件，筛选结果已展示
* 测试步骤:
* 1.设置多个筛选条件并确认筛选，验证筛选结果已更新
* 2.点击"重置"或"清空筛选"按钮
* 3.验证所有筛选条件是否恢复为默认（全部/未选中）状态
* 4.验证代码仓列表是否恢复为全量数据展示
* 预期结果:
* 重置功能可一键清空所有筛选条件，代码仓列表恢复全量展示

**5. 筛选无结果时的展示测试**:
* 前置条件:存在多维度代码仓数据
* 测试步骤:
* 1.设置一组不存在的组合筛选条件（如：平台=不存在的平台+语言=不存在的语言）
* 2.验证筛选结果区域是否展示"无数据"或空状态提示
* 3.确认空状态提示文案清晰友好
* 4.清空筛选条件后，验证列表恢复正常
* 预期结果:
* 筛选无结果时展示友好的空状态提示，不出现页面异常或报错

**6. 筛选条件变更后的结果刷新测试**:
* 前置条件:已筛选展示部分结果
* 测试步骤:
* 1.设置初始筛选条件，记录筛选结果数量和内容
* 2.变更其中一个筛选条件（增加或移除某个选项）
* 3.验证筛选结果是否立即刷新并与新条件匹配
* 4.逐一变更各维度筛选条件，验证每次变更后结果刷新准确
* 预期结果:
* 筛选条件变更后，结果及时准确刷新，无需手动刷新页面

* 3.验证筛选结果数量是否有展示（如"共X条"）
