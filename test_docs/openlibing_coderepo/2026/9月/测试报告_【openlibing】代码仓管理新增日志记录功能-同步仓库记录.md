## 2. 测试过程

### 2.1 功能测试专项

**1.手动同步进度端到端验证**:
* 预期结果: 进度从 0 递增至 total（= 该项目全量仓数），currentRepo 实时切换，无失败时失败数为 0，结束后仓库列表自动刷新一次
* **测试结果**： Passed
* **证明截图**: 待补充

**2.进度 popover 三态展示验证**:
* 预期结果: none 显示「暂无进行中的同步任务」；running 显示百分比进度条 + 已完成 x/y + 正在同步：{当前仓} + 失败数（>0 红色）+ 触发方式；finished 显示完成态
* **测试结果**： Passed
* **证明截图**: 待补充

**3.按钮状态与轮询状态机验证**:
* 预期结果: running 期间按钮 disabled+loading 且拒绝二次提交；running → finished 触发一次按钮恢复 + 列表刷新 + success 提示；running → none 静默恢复；串行轮询任意时刻最多一个在途请求
* **测试结果**： Passed
* **证明截图**: 待补充

**4.页面进入 / 刷新状态恢复验证**:
* 预期结果: 同步中刷新页面后按钮禁用、进度恢复、轮询续接；首查 finished / none 不触发列表刷新与提示
* **测试结果**： Passed
* **证明截图**: 待补充

**5.页面链路与 XxlJob 链路互斥验证**:
* 预期结果: 同步期间二次点击返回「当前项目正在同步仓库信息，请稍后重试」；XxlJob step2 / step8 拿不到锁时跳过该项目本轮并记录日志、不阻塞整轮
* **测试结果**： Passed
* **证明截图**: 待补充

**6.R2 XxlJob projectId 参数化验证**:
* 预期结果: 指定 `projectId=xxx` 时 step1 / step2 / step5-6 / step8 仅处理该项目，step3 / 4 / 7 保持全局；非法参数 handleFail 退出；不传参数行为不变
* **测试结果**： Passed
* **证明截图**: 待补充

**7.R3 全局配置变更中断重跑验证**:
* 预期结果: 旧任务在仓边界检查点中断并释放锁，新任务在 60s 等待窗口内获锁并按新配置全链路重跑，进度短暂 finished → running 属预期，重跑不再被静默丢弃
* **测试结果**： Passed
* **证明截图**: 待补充

### 2.4 安全与隐私测试专项

**1.横向越权校验验证**:

**2.入参校验验证**:
* 预期结果: userId / projectId 为空或缺失时 `@NotBlank` / `@NotNull` 校验生效并返回参数错误
* **测试结果**： Passed
* **证明截图**: 待补充

**3.敏感信息与注入面验证**:
* 预期结果: 进度返回不含 `accessToken` 等敏感信息；Redis key 由 Integer projectId 拼接，无注入面
* **测试结果**： Passed

### 2.5 可靠性与韧性测试专项

**1.进程崩溃自愈验证**:
* 预期结果: 同步中实例崩溃（无 finishProgress）后 status 停留 running 至 30min TTL 过期，查询返回 none，前端按钮自动恢复
* **测试结果**： Passed
* **证明截图**: 待补充

**2.超长同步 inFlight 不泄漏验证**:
* 预期结果: finally 按 `inFlight-- → finishProgress → isHeldByCurrentThread 才 unlock` 执行，锁过期后 unlock 异常不再导致 `inFlight--` 被跳过，项目不被永久卡「同步中」
* **测试结果**： Passed
* **证明截图**: 待补充

**3.锁 key 统一与跨版本互斥验证**:
* 预期结果: job step2 / step8 复用 `PROJECT_SYNC_LOCK_PREFIX` 同一 key，滚动发布期跨版本互斥成立，进度 Hash 与锁 key 相互独立
* **测试结果**： Passed
* **证明截图**: 待补充
