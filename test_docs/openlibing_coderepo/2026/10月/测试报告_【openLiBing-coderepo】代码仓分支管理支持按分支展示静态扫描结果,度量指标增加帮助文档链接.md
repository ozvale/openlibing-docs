## 5. 补充说明

分支管理页新增静态扫描结果列，展示形态以实际提测 UI 为准记录，核心断言锚定"分支级口径 = 下钻明细页过滤后口径"且分支间数据独立互不串计；点击静态扫描结果下钻到告警明细页并自动携带分支过滤条件，特殊字符/超长分支名编码正确不丢失不截断，无扫描结果分支交互（置灰不可点或带条件下钻为空列表）以实际实现记录结论；代码度量指标、UT 覆盖率两类度量列均补充帮助文档跳转链接，链接各自指向正确文档且全部可达非 404，帮助文档内容质量不在测试范围；codecheck/coderepo 两侧打通分支粒度静态扫描结果查询，同参返回一致，仓库级汇总口径与改前基线一致，存量仓库默认分支/仓库列表页既有仓库级静态扫描结果展示零回归与多仓库抽查收口至存量回归（界面比对改前基线）覆盖；接口断言校验响应体错误码字段而非仅 HTTP 状态码，branch 携带 SQL 注入串时参数化查询生效无放大。
