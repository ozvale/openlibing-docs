## 3. 专项验证设计和执行详情

### 3.1 功能测试专项

**1.统一表查询（只读统一表）**:

- 测试步骤: 以项目成员账号调用 CICD `POST /logging/pipelineLog/list`、coderepo `POST /logging/list`，核对返回记录与统一表数据；翻页核对分页一致性；核对查询仅返回白名单模块范围
- 预期结果: 返回统一表记录；字段完整可核对；分页无重复；历史数据不迁移、不做新旧表 UNION

**2.列头筛选候选与计数**:

- 测试步骤: 调用 `POST /logging/filter-meta`，核对返回候选项与计数；保留已选值核对真实计数；构造异常参数
- 预期结果: 候选项与计数正确；已选值保留；异常参数容错

**3.关键增删改操作日志记录（代码仓/流水线）**:

- 测试步骤: 依次执行代码仓录入/编辑/同步/删除、编辑分支、成员增删改；流水线创建/编辑/删除、保存为模板、执行或失败节点重跑；核对统一表产生对应记录
- 预期结果: 各操作成功后产生对应记录，字段完整（项目、资源、操作人、结果、新旧数据、起止时间）

**4.异步任务时间语义**:

- 测试步骤: 页面投递成功立即返回的入口核对不提前写完成日志；触发投递失败场景核对单独补记且不重复；定时任务核对 begin「进行中」/ finish 同 ID 更新
- 预期结果: 同一任务不产生重复记录；起止时间为实际执行时间

### 3.2 体验测试专项

**1.项目页日志查询与列头筛选**:

- 测试步骤: 进入 CICD 流水线项目页 / 代码仓项目页操作日志入口；检查列表列展示与真实操作一致；使用列头筛选按模块/操作人筛选；查看详情核对脱敏后新旧数据；翻页核对分页一致
- 预期结果: 数据正确、字段完整、查询仅覆盖本项目；列头筛选候选与计数正确、已选值保留

### 3.3 安全与隐私测试专项

**1.认证与横向越权校验**:

- 测试步骤: 无认证访问日志查询接口；使用无该项目权限的 userId 查询；跨项目查询
- 预期结果: 无认证/非成员/跨项目均被拒或无数据，项目间隔离有效

**2.敏感信息防护**:

- 测试步骤: 在成功/失败/异常/超限场景检查日志查询结果字段
- 预期结果: 结果不含 token、密码、密钥等敏感内容

### 3.4 性能与伸缩性专项

**1.多服务并发写日志完整性与数量对账**:

- 测试步骤: 在受控环境由 CICD/coderepo 及至少一个其它接入服务并发写日志
- 预期结果: 记录完整（不丢失、不重复），数量对账一致

**2.突发压力下可见延迟与队列恢复**:

- 测试步骤: 注入突发压力，观测日志写入可见延迟与压力后队列恢复
- 预期结果: 可见延迟可观测，压力后队列可恢复

**3.写入繁忙/失败降级**:

- 测试步骤: 构造队列满/限流/超时/重试耗尽场景
- 预期结果: 有失败记录或指标，不改写已成功业务结果
