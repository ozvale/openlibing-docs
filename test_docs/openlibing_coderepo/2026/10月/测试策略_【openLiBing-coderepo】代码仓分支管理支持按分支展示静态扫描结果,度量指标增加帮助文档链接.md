## 3. 专项验证设计和执行详情

### 3.1 功能测试专项

**1.分支管理静态扫描结果列展示与数值正确性验证**:

- 前置条件: 已接入静态扫描的仓库 R（含分支 B1/B2/B3，B1、B2 有分支级扫描结果且可区分，B3 无扫描结果）；未接入/无分支的仓库 S；测试账号具备代码仓管理与代码检查页面权限
- 测试步骤:
  1. 进入仓库 R 分支管理页，断言列表新增"静态扫描结果"列且默认可见（展示形态以实际提测 UI 为准，记录结论）
  2. 记录 B1、B2、B3 各行静态扫描结果展示值，分别下钻到告警明细页按对应分支过滤，逐一比对
  3. 断言多分支仓库各分支静态扫描结果相互独立（B1 的结果不计入 B2 行）
  4. B3（无扫描结果分支）行，断言展示空/0 且不报错
  5. 仓库 S（无分支/未接入）分支管理页，断言页面正常、静态扫描结果列为空或 0
  6. 触发一次静态扫描（或新增扫描数据）后刷新分支管理页，断言对应分支结果刷新正确
- 预期结果: 静态扫描结果列正常展示；各分支结果与下钻明细页按分支过滤后的结果完全一致；分支间数据独立互不串计；无扫描结果展示空/0 不报错；数据刷新后展示同步

**2.静态扫描结果点击下钻与分支条件传递验证**:

- 前置条件: TC-ISSUE205-001 前置数据就绪（B1/B2 有扫描结果、B3 无）；存在含空格、中文、`/` 的特殊字符分支名且带扫描结果；存在超长分支名（200+ 字符）分支 1 个；测试账号具备代码检查页面权限
- 测试步骤:
  1. 点击 B1 行静态扫描结果，断言下钻到告警明细页且过滤器自动带上分支=B1
  2. 断言下钻后列表数据仅为 B1 分支的扫描结果（与分支管理页记录的过滤后结果一致）
  3. 点击 B3 行（无扫描结果），断言交互符合设计（置灰不可点或带条件下钻为空列表，以实际实现记录结论）
  4. 点击特殊字符分支名的扫描结果，断言 URL 中分支名正确编码、下钻后过滤器展示原分支名、过滤结果正确
  5. 点击超长分支名扫描结果，断言编码后 URL 可正常下钻不截断、过滤正确
  6. 浏览器后退返回分支管理页，再次点击其他分支扫描结果，断言无串态
- 预期结果: 点击下钻均携带正确分支过滤条件；过滤后数据与分支管理展示一致；特殊字符/超长分支名编码正确不丢失不截断；无扫描结果分支交互符合设计；多次下钻无串态

**3.度量指标帮助文档链接验证**:

- 前置条件: 分支管理页存在代码度量指标、UT 覆盖率度量列且有数据展示；开发已提供帮助文档目标链接清单（内外网地址，如区分）
- 测试步骤:
  1. 检查代码度量指标列，断言存在帮助文档跳转入口（帮助小图标或链接，样式符合平台规范）
  2. 检查 UT 覆盖率列，断言同样存在帮助文档跳转入口
  3. 点击代码度量指标帮助链接，断言跳转到对应帮助文档页面且文档内容与"代码度量指标"对应
  4. 点击 UT 覆盖率帮助链接，断言跳转文档与"UT 覆盖率"对应（两类指标链接各自指向正确文档，不互相错指）
  5. 断言全部帮助链接可达（非 404/非空白页）；如内外网地址不同则分别验证
  6. 检查帮助入口不破坏度量列原有数据展示与列布局
- 预期结果: 两类度量指标列均存在帮助文档跳转入口且样式规范；跳转文档指向正确（指标含义/数据来源说明）；链接全部可达非 404；度量列原有数据展示不受影响

**4.分支粒度静态扫描查询接口参数校验与存量兼容验证**:

- 前置条件: beta 环境可访问；API 账号具备代码仓管理权限；仓库 R（B1 有扫描结果 S1 条、B2 有 S2 条，S1≠S2），接口路径与参数名以提测接口文档为准；仓库列表页既有仓库级静态扫描结果的改前行为已知（改前数值记录为基线）
- 测试步骤:
  1. 有效类：带 repoId + branch=B1 查询，断言 200 且返回 S1；branch=B2 查询，断言返回 S2（分支过滤生效且相互独立）
  2. 有效类：branch 传不存在的分支名，断言 200 且返回空结果（非报错）
  3. 无效类：缺 repoId / repoId 不存在，断言明确业务错误码（非 500）；边界：branch 超长/空串不 500；branch 携带 SQL 注入串与特殊字符，断言参数化查询生效、无放大效果
  4. 两侧一致性：同一 repoId+branch 分别调 codecheck 侧与 coderepo 侧查询，断言返回结果一致（打通口径统一）
  5. 存量兼容：仓库级汇总调用（不含分支维度的既有调用），断言仓库 R 仓库级汇总值与改前基线一致（分支粒度打通不改变仓库级口径）
- 预期结果: 分支过滤有效类数值正确且独立；无效类明确业务错误码；注入无放大；codecheck/coderepo 两侧同参返回一致；仓库级汇总口径与改前基线一致
