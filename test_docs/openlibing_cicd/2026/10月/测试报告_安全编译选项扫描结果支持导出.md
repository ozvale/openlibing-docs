## 2. 测试过程

### 2.1 功能测试专项

**1.导出任务创建接口契约与导出中心任务登记（AC1）**:

- 预期结果: `POST /build-artifact/sec-option/detail/export` 创建成功 → 导出中心 SUCCESS → 详情/下载；类型 `SEC_OPTION_DETAIL`、objectKey `日期/UUID` 规范符合
- **测试结果**： Passed（TC-ISSUE495-001）

**2.导出 Excel 文件名与扫描概览 Sheet 一致性（AC2）**:

- 预期结果: 文件名 `安全编译选项扫描详情_{产物名称}_{recordId}.xlsx`；Sheet1「扫描概览」8 行基础信息 + 14 项指标与详情页 overview 逐项一致
- **测试结果**： Passed（TC-ISSUE495-002）

**3.文件扫描结果 Sheet 明细与备案标注（AC2）**:

- 预期结果: Sheet2「文件扫描结果」逐文件逐选项与详情页弹窗一致；命中备案记录单元格附加「（已备案）」；顺序与弹窗一致
- **测试结果**： Passed（TC-ISSUE495-003；119 行逐文件逐选项一致，4 处「（已备案）」与概览已备案数一致；零文件记录仅输出「扫描概览」，口径已确认）

**4.大批量文件分批查询完整性与排序一致性（AC2）**:

- 预期结果: Sheet2 按 1000 条分批查询，边界行数完整、无重复、排序与弹窗一致、末行完整
- **测试结果**： Passed（TC-ISSUE495-004；999/1000/1001/2500 四边界导出行数与基准一致、集合双向 diff 为空）

**5.覆盖率颜色规则与选项映射配置（AC2）**:

- 预期结果: 覆盖率颜色四档（绿/黄/红/灰）与阈值一致（≥80% 绿、50%~79% 黄、<50% 红、N/A 灰）；14 项展示名/描述齐全
- **测试结果**： Passed（TC-ISSUE495-005；绿 `#16A34A` / 黄 `#E6A23C` / 红 `#DC2626` / 灰 `#9CA3AF`）

**6.导出接口参数校验与异常语义（健康度）**:

- 预期结果: 7 类无效入参均被拒绝且无脏任务；零文件记录导出成功
- **测试结果**： Passed（TC-ISSUE495-007）

**7.详情页导出入口与导出中心浮窗端到端（AC1）**:

- 预期结果: 详情页存在导出按钮；点击后通过无界 bus 唤起导出中心浮窗，成功后自动下载 Excel
- **测试结果**： Passed（TC-ISSUE495-008；自动下载 23078 字节 Excel，概览 24 行 + 文件 268 行；未出现「未找到对应的扫描记录」）

### 2.2 安全与隐私测试专项

**1.导出接口纵向鉴权与项目成员横向校验（AC3）**:

- 预期结果: 未登录/无效令牌被拦截；非项目成员/无角色用户被拒绝；项目成员正常导出
- **测试结果**： Passed（TC-ISSUE495-009；未登录/无效令牌拦截，user2 对无角色项目被拒，user1 正常导出）

**2.recordId 跨项目归属越权与导出数据范围一致性（AC3）**:

- 预期结果: 项目 A `projectId` + 项目 B `recordId`、枚举记录均被拒绝且无任务；正常导出数据范围与详情页严格一致
- **测试结果**： Passed（TC-ISSUE495-010）

## 4. 遗留问题与风险说明

| 缺陷 ID                                                   | 缺陷描述                                     | 严重程度 | 处理意见                                                   |
| --------------------------------------------------------- | -------------------------------------------- | -------- | ---------------------------------------------------------- |

### 4.1 口径确认与观察项

| 事项                                                          | 结论                       | 说明                                                                                                                    |
| ------------------------------------------------------------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 零文件记录导出仅含「扫描概览」、无「文件扫描结果」Sheet       | 接受（2026-10-28 确认）    | 零文件时无明细可列，不产出空 Sheet 符合使用者逻辑；建议需求文档将 AC2「含两个 Sheet」修订为「有文件明细时含两个 Sheet」 |
| 跨项目/不存在 recordId 返回业务码 500「未找到对应的扫描记录」 | 拒绝有效，建议产品确认语义 | 未产生导出任务、未泄露归属信息；但错误码为 500 而非 403/400，建议统一为明确业务错误码供前端区分提示                     |
| 导出文件顺序与 Python/ASCII 字典序不一致                      | 非缺陷                     | 与详情页弹窗展示顺序完全一致，符合「与弹窗一致」的用户口径                                                              |

### 4.2 遗留风险

- **TC-006 导出失败链路**（FAILED 回写、失败原因、临时文件清理）缺少稳定注入手段，复现成本高、影响面小，经评估风险可接受，本版本跳过（2026-10-28 决策）；后续若引入导出失败注入开关，补一条 AC4 回归。
- 导出中心浮窗进度未做 DOM 级断言（疑似 iframe/Shadow DOM），仅以下载与任务结果为准。
