## 3. 专项验证设计和执行详情

### 3.1 功能测试专项

**1.导出任务创建接口契约与导出中心任务登记（AC1）**:

- 测试步骤: 调用 `POST /build-artifact/sec-option/detail/export`（入参 `projectId` + `recordId`）→ 查询 `/export/list`、`/export/detail` 核对任务类型与状态 → 获取 `/export/download-url` 下载
- 预期结果: 创建成功 → SUCCESS → 可下载；类型 `SEC_OPTION_DETAIL`、objectKey `日期/UUID` 规范符合

**2.导出 Excel 文件名与扫描概览 Sheet 一致性（AC2）**:

- 测试步骤: 解析下载文件，核对文件名与 Sheet1 内容
- 预期结果: 文件名 `安全编译选项扫描详情_{产物名称}_{recordId}.xlsx`；8 行基础信息 + 14 项指标与详情页 `overview` 逐项一致

**3.文件扫描结果 Sheet 明细与备案标注（AC2）**:

- 测试步骤: 解析 Sheet2，与 `file-detail`/`filing/list` 逐行逐项对照
- 预期结果: 文件矩阵（文件名/路径 + 14 选项列 YES/NO/N/A）与弹窗一致；命中备案记录附加「（已备案）」

**4.大批量文件分批查询完整性与排序一致性（AC2）**:

- 测试步骤: 对 999/1000/1001/2500 文件的记录导出，核对行数、去重、顺序、末行完整性
- 预期结果: 导出行数与基准一致、无重复、集合双向 diff 为空、顺序与弹窗一致

**5.覆盖率颜色规则与选项映射配置（AC2）**:

- 测试步骤: 核对 Excel 覆盖率单元格颜色与选项列头
- 预期结果: 四档颜色（≥80% 绿 / 50%~79% 黄 / <50% 红 / N/A 灰）与阈值一致；14 项展示名/描述齐全

**6.导出接口参数校验与异常语义（健康度）**:

- 测试步骤: 传入 7 类无效入参，核对错误语义与是否产生脏任务
- 预期结果: 均被拒绝且无脏任务；零文件记录导出成功

**7.详情页导出入口与导出中心浮窗端到端（AC1）**:

- 测试步骤: 详情页点击「导出」→ 观察导出中心浮窗与进度 → 等待自动下载
- 预期结果: 按钮存在、浮窗正常唤起、成功后自动下载 Excel

**8.导出失败状态回写与临时文件清理（AC4）**:

- 测试步骤: 构造/注入导出失败（如临时置空 OBS 配置、使用不可写临时目录或注入生成异常），观察任务状态、失败原因与本地临时目录
- 预期结果: 任务状态置为 FAILED 并记录失败原因（失败原因脱敏，不含堆栈与内网绝对路径）；本地临时文件被清理；导出中心无残留进度态

### 3.2 安全与隐私测试专项

**1.导出接口纵向鉴权与项目成员横向校验（AC3）**:

- 测试步骤: 未登录/无效令牌调用创建接口；以非项目成员/无角色账号调用；项目成员正常导出
- 预期结果: 未登录/无效令牌/非成员被拒绝；项目成员正常导出

**2.recordId 跨项目归属越权与数据范围一致性（AC3）**:

- 测试步骤: 以项目 A `projectId` + 项目 B `recordId`、枚举 recordId 调用
- 预期结果: 被拒绝且无任务；正常导出数据范围与详情页严格一致
