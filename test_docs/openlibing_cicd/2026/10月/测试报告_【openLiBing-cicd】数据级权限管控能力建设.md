## 5. 补充说明

不新增角色表，在 user_role_info 表基础上新增 perm_group_id 字段，存量数据默认 0（默认分组）；删除权限组自动连带清理成员记录，不提供保留选项；所有 @CheckPermission 接口在绑定权限组后均需按权限组过滤，包括查看操作；三个全局角色（admin/super_admin/platform_operater）绕过权限组检查；cicd 鉴权 RPC 失败 fail-closed（拒绝访问）；权限组 API 路径已重命名为 query-groups/create-group/update-group/delete-group/bind-resource 等；framework 先行部署，其余 7 服务随后适配；单条流水线通过绑定不同权限组控制组内成员可见可操作、组外用户查看收紧且操作拒绝。
