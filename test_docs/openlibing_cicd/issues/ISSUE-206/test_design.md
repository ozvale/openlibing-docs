# ISSUE-206 测试设计

> 基于 [test_strategy.md](test_strategy.md) v1.2 与 Issue 206 开发设计文档生成。

## 1. 设计概述

本 Issue 的测试设计基于开发设计文档（Issue 206：机机接口下线切换 apig），覆盖以下功能点：

- FP1: recordPipelineInfo 接口 APIG 新路径功能验证
- FP2: pipLineDetailInfo 接口 APIG 新路径功能验证
- FP3: code-cooperate-url 接口 APIG 新路径功能验证
- FP4: APIG App 认证校验（正向 + 反向）
- FP5: 旧路径双跑回归（过渡期）
- FP6: 异常参数容错
- FP7: machine_interface 冗余登记清理验证

### 1.1 设计原则

- 手工用例与自动化用例分离
- 自动化用例需标注脚本位置
- 每个用例需记录用例类型
- 每个功能点需标注所采用的测试设计方法

### 1.2 用例类型定义

| 类型代码  | 类型名称    | 说明                  |
| --------- | ----------- | --------------------- |
| manual    | 手工执行    | 需要人工操作执行      |
| auto_ui   | 自动化-UI   | UI自动化测试脚本      |
| auto_api  | 自动化-API  | API接口自动化测试脚本 |
| auto_perf | 自动化-性能 | 性能测试脚本          |
| auto_sec  | 自动化-安全 | 安全测试脚本          |

### 1.3 测试设计方法

- [x] 等价类划分（认证有效性等价类）
- [ ] 边界值分析
- [ ] 决策表测试
- [ ] 状态迁移测试
- [x] 场景法（单接口正向调用场景、登记清理状态检查）
- [x] 错误推测法（伪造签名、异常参数）
