## 4. 测试结论

### 4.1 结论

> 取值：允许发布 / 附条件发布 / 暂不允许发布（见规则 03 第5.2节）

**允许发布**

### 4.2 结论依据

- **功能覆盖**: Issue 目标 1（第 2 类 3 个机机接口 APIG 新路径迁移验证）与目标 2（machine_interface 冗余登记清理）全覆盖；覆盖维度含正向功能（3 接口真实数据验证）、App 认证正反向（无认证/错误 AppCode/伪造签名均被拒）、旧路径双跑回归、异常参数容错。范围裁剪项（gitee 相关接口不测、gitcode webhook 手工端到端已验证、旧路径下线断言不测）均已由测试人员确认（见 test_strategy.md §2）
- **L0用例结果**: 全部通过（1/1，含唯一有生产流量的 recordPipelineInfo 接口）
- **L1用例结果**: 全部通过（6/6）
- **L2用例结果**: 全部通过（2/2）
- **遗留风险**:
  1. **projectId 参数语义不一致**：同批迁移接口中 recordPipelineInfo 要求 openlibing 平台项目ID、pipLineDetailInfo 要求华为云项目ID（源码按 `HwProjectInfoEntity.hwProjectId` 匹配，为既有设计非本次引入）。调用方切换 APIG 时易混淆，建议开发统一参数语义或在接口文档中明确说明
  2. **调用方适配注意**：网关强制校验请求体与 Content-Type 匹配（GET 请求亦需携带 JSON body，缺失报 400 APIG.0602）；实际调用路径前缀为服务名（`/openlibing-cicd/v1/...`，Issue 中 `/apig` 为模板前缀）
  3. **双跑期窗口**：旧路径回归用例 TC-ISSUE206-007 为过渡期专用，旧路径正式下线后应置 deprecated 并补充下线断言用例
