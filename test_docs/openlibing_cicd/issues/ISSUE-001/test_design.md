# ISSUE-001 测试设计

## 1. 设计概述

本 Issue 测试设计围绕"流水线模板"功能展开，覆盖模板保存、列表查询、基于模板创建流水线、模板权限隔离四类功能点。

### 1.1 设计原则

- 手工用例与自动化用例分离
- 自动化用例需标注脚本位置
- 每个用例需记录用例类型

### 1.2 用例类型定义

| 类型代码  | 类型名称    | 说明                  |
| --------- | ----------- | --------------------- |
| manual    | 手工执行    | 需要人工操作执行      |
| auto_ui   | 自动化-UI   | UI自动化测试脚本      |
| auto_api  | 自动化-API  | API接口自动化测试脚本 |
| auto_perf | 自动化-性能 | 性能测试脚本          |
| auto_sec  | 自动化-安全 | 安全测试脚本          |

## 2. 功能点分析

| 功能点             | 测试类型          | 优先级 | 备注             |
| ------------------ | ----------------- | ------ | ---------------- |
| 保存流水线为模板   | manual + auto_api | P0     | 含字段完整性校验 |
| 模板列表查询       | auto_api          | P1     | 分页、筛选       |
| 基于模板创建流水线 | manual + auto_api | P0     | 字段一致性校验   |
| 模板越权访问       | auto_api          | P0     | 横向越权         |
