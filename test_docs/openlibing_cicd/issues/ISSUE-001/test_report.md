### 缺陷详情 - BUG-001

- **复现步骤**：
  1. 用户 A 创建私有模板 T1
  2. 用户 B 使用自己的 token 调用 `GET /api/v1/templates/{T1}` 查询接口
- **实际结果**: 接口返回 200，响应体包含 T1 的完整配置内容
- **预期结果**: 接口返回 403 或 404，不返回模板内容
- **影响范围**: 私有模板存在横向越权泄露风险
- **复现概率**: 100%
