## 2. 测试目标

验证用户可将已配置的流水线保存为模板，并能通过模板一键创建新流水线，新流水线配置与模板一致且可正常触发执行。

## 3. 测试范围

| 测试类型 | 是否覆盖 | 说明 |
|----------|----------|------|
| UI功能测试 | 是 | 模板保存/列表/选择/创建的页面交互 |
| API接口测试 | 是 | 模板增删查改、基于模板创建流水线接口 |
| 性能测试 | 否 | 非高频接口，本期不覆盖 |
| 安全测试 | 是 | 模板越权访问校验（他人私有模板不可见/不可用） |

## 4. 测试策略

### 4.1 手工测试
- 覆盖 UI 交互类场景：模板保存表单校验、模板列表展示、模板选择创建向导
- 覆盖兼容性/异常类场景：模板配置缺失字段时的容错提示

### 4.2 自动化测试
- API 层：模板 CRUD、基于模板创建流水线、越权访问校验
- 自动化用例脚本位置: `src/tests/openlibing/openlibing-cicd/pipeline/`

## 5. 风险与约束

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 模板与流水线配置字段未完全对齐 | 创建出的流水线配置缺失 | 用例校验全部字段一致性 |
| 跨用户模板权限未隔离 | 越权访问他人私有模板 | 增加横向越权自动化用例 |
