# 提供一键举报机制，收到问题反馈后，立马将此工具全面下架，并提供手动处理按钮 测试策略

## 1. 基本信息

* **需求链接**: https://gitcode.com/openlibing/openlibing-framework/issues/46
* **需求名称**: [需求]:openLiBing工具箱管理-支持工具上传下载和在线工具
* **核心目标**:
  验证工具箱的一键举报机制：举报后立即将工具全面下架、工具管理者收到举报邮件通知、审批人通过我的待办手动处理（审批通过维持停用、审批不通过激活工具），以及工具被下架后无法上传新版本等关键链路的正确性。
* **开发责任人**: 李婷,张强
* **测试责任人**: 张创
