## 1. 设计概述

本Issue的测试设计基于开发设计文档（Issue 106 描述）与 beta 环境页面探索事实，覆盖以下功能点：精准测试菜单入口、项目级看板路由与页面加载、无权限访问拦截、匿名访问拦截、低权限访问拦截、项目级看板覆盖率指标展示（blocked）、文件下钻覆盖详情（blocked）、组织级看板指标展示（blocked）、OBS 数据来源路径映射（blocked）。

### 1.1 设计原则

- 手工用例与自动化用例分离
- 自动化用例需标注脚本位置
- 每个用例需记录用例类型
- 每个功能点需标注所采用的测试设计方法

### 1.2 用例类型定义

| 类型代码 | 类型名称 | 说明 |
|----------|----------|------|
| manual | 手工执行 | 需要人工操作执行 |
| auto_ui | 自动化-UI | UI自动化测试脚本 |
| auto_api | 自动化-API | API接口自动化测试脚本 |
| auto_perf | 自动化-性能 | 性能测试脚本 |
| auto_sec | 自动化-安全 | 安全测试脚本 |

### 1.3 测试设计方法

本设计采用以下方法（详见 ai-rules/01-requirement-driven-test-design.md 第4节）：

- [x] 等价类划分（Equivalence Partitioning）
- [x] 边界值分析（Boundary Value Analysis）
- [ ] 决策表测试（Decision Table Testing）
- [ ] 状态迁移测试（State Transition Testing）
- [x] 场景法（Use Case / Scenario Testing）
- [x] 错误推测法（Error Guessing）
