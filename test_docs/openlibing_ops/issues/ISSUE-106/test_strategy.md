## 2. 需求摘要

> 依据 Issue 原文与 beta 环境页面探索（探索记录按「四件套唯一产物」约定于 2026-09-01 移出 Issue 目录，可查 git 历史 `page_exploration.md`），**禁止超出文档范围**。

新增两个精准测试看板：

- **项目级看板**：展示项目代码的行、分支、函数、文件四种覆盖率，支持下钻到具体文件查看文件内容的覆盖详情。数据来源为业务按规定路径上报到 openlibing OBS 的覆盖率文件 + 源码压缩包，通过路径映射组织和项目。
- **组织级看板**：展示组织的精准测试接入项目数、精准测试访问量、pr 渗透率、pr 减少工作量、pr 时长降幅，以及行/分支/函数/文件覆盖率（来自项目级看板）。

**页面探索补充事实**：beta 环境已上线「测试管理 → 精准测试」菜单，前端路由 `/apps/coverageDashboard`，页面名「测试用例覆盖看板」；当前高权限测试账号**无访问权限**（重定向至 noPermission 页）。

## 3. 测试目标

1. 验证精准测试看板入口、路由注册与基础可达性（可立即执行）
2. 验证无权限账号的访问拦截行为（可立即执行）
3. 验证未登录（匿名）访问看板路由被拒绝（安全-认证校验，可立即执行）
4. 验证项目级看板四种覆盖率展示与文件下钻（**blocked：账号无权限**）
5. 验证组织级看板六类指标展示（**blocked：账号无权限 + 入口待确认**）

## 4. 测试范围

| 测试类型    | 是否覆盖 | 说明                                                                                    |
| ----------- | -------- | --------------------------------------------------------------------------------------- |
| UI功能测试  | 是       | 菜单入口、路由可达、无权限拦截、页面名称（批次一）；覆盖率展示与下钻（批次二，blocked） |
| API接口测试 | 否       | Issue 未提供看板接口清单；权限开通后页面探索采集到接口再补充                            |
| 性能测试    | 否       | Issue 非功能需求章节为空，无性能指标；权限开通后再评估                                  |
| 安全测试    | 部分     | 覆盖认证校验（匿名访问）与纵向越权（低权限访问）两个维度；其余维度见 5.2 声明           |

## 5. 测试策略

### 5.1 手工测试

- 批次二用例（blocked 状态归档，权限开通后执行）：项目级看板覆盖率指标展示、文件下钻覆盖详情、组织级看板指标展示、OBS 数据来源路径映射
- 手工用例归档位置: `assets/docs/openlibing/openlibing_ops/test_case.md`（openlibing_ops 为历史非标准目录，统一清单）

### 5.2 自动化测试

- 批次一（立即执行）：UI 入口/路由/拦截用例 + 安全认证用例
- 自动化用例归档位置: `assets/docs/openlibing/openlibing_ops/test_case.md`
- 自动化脚本位置:
  - `src/tests/openlibing/openlibing_ops/ui/beta/coverage_dashboard/`
  - `src/tests/openlibing/openlibing_ops/security/beta/coverage_dashboard/`

**安全维度覆盖声明（规则 04 强制）**：

| 维度                                | 覆盖状态 | 原因                                                                |
| ----------------------------------- | -------- | ------------------------------------------------------------------- |
| 认证校验 (auth_check)               | 覆盖     | 未登录访问看板路由应被拦截                                          |
| 纵向越权 (vertical_check)           | 覆盖     | 低权限账号访问看板路由应被拦截                                      |
| CSRF 防护 (csrf_check)              | 不覆盖   | 看板为只读展示页面，Issue 未提供变更类接口，无 CSRF 场景            |
| 横向越权 (horizontal_check)         | 不覆盖   | 看板按组织/项目聚合展示，Issue 未定义跨用户私有资源语义，无接口清单 |
| 传输安全 (transport_check)          | 不覆盖   | beta 环境全站 HTTPS 已由既有基线（2026-08-11）覆盖，本期不重复      |
| 敏感信息防护 (sensitive_data_check) | 不覆盖   | 当前账号无权限无法获取看板响应体；权限开通后补充                    |

## 6. 风险与约束

| 风险                 | 影响                              | 缓解措施                                              |
| -------------------- | --------------------------------- | ----------------------------------------------------- |
| 测试账号无看板权限   | 项目级/组织级看板内容验证全部阻塞 | 用例标记 block 归档；提醒用户联系管理员开通权限后复测 |
| 组织级看板入口未知   | 组织级指标验证无入口              | 已标记待确认；权限开通后页面探索补充确认              |
| Issue 无接口清单     | API/数据来源类验证无法设计自动化  | 手工用例覆盖 OBS 路径映射，接口清单补充后再自动化     |
| Issue 非功能需求为空 | 无性能基线                        | 权限开通后与需求方确认性能指标再补充                  |
