### 1.2 需求摘要

> 引用 `测试过程数据/需求分析文档.md` 1.2 / 1.6 / 1.7 / 1.8，不重复抄写。

- **核心功能点**：FP-01 申请表数据接入（数据侧产出新 Doris 表，后端只读）、FP-02 资源运营看板计算逻辑切换（9 个接口取数从任务×小时切片表改申请表）、FP-03 工程能力看板排队三指标切换（buildQueueP90/dtQueueP90/resourceQueueTime）、FP-04 CPU/内存维度（工作假设本期不上板）。
- **接口**：`/resource-operation/summary|trend|heatmap|run-analysis|project-alloc-trend`（5 个）+ `/common/detail` 4 个 category（ops-resource-pool-detail / ops-project-resource-efficiency / ops-pipeline-resource-efficiency / ops-pipeline-run-detail）+ `/ops-overview/main`（排队三指标）+ `/common/refresh-time`；**契约全部不变，仅内部数据源切换**（Q-03 用户确认）。
- **业务规则**：BR-01~BR-07（时间窗口 ≤7 天、项目隔离、率值精度、申请表字段、排队/运行时长直取字段、跨小时切片分摊、申请粒度逐条计入不去重）。
- **异常场景**：EX-01~EX-06（跨小时切片、运行中按当前时间截断、取消/失败排队计入运行 0、数据缺失空结构、历史回填无缝切换、同任务多申请不去重）。
- **实现状态**：提测前未知（申请表表名/DDL/产出链路待提测确认 P-01）；Q-05~Q-08 四项按工作假设设计，提测核对。
