### 1.3 测试目标

1. 新字段透出与计算口径正确（FP1）：项目效率表格 6 新字段全量透出；平均消耗 = PR 卡时÷运行次数；使用率系列与 #210 口径一致（Σassign_npu_hours ÷ Σ(IFNULL(actual_npu_num,total_npu_num)×24×天数)）；利用率系列拆分沿用宽表口径；接口值与 Doris 真值对拍一致
2. 列设置交互正确（FP2）：默认显隐符合设计（5 显 4 隐）、切换持久、新列条目齐全
3. 排序正确（FP3）：4 新排序字段升/降序正确、白名单扩展、非法 sortField 拒绝
4. 下钻链路正确（FP4/FP5）：下钻统计卡第 4 项、流水线表 PR/Nightly 两页签新列、天级曲线图数据与页签联动、时间范围与全局筛选一致
5. 性能与安全基线：项目效率接口（新增多字段聚合）与天级趋势接口响应时间；认证/横向越权（跨项目 detail 数据隔离）/传输/敏感信息防护
6. 数据陷阱防护：无 PR 运行项目（TorchNPU-GitHub，分母为零）、多 IP 任务 SUM 口径、池名尾随空格、机器跨池重叠扇出、无项目绑定池（SGLang/vllm）不出现
