### 缺陷详情

#### #259: 独占池NPU使用率与共享池NPU使用率的计算公式错误

- **关联用例**: TC-ISSUE211-032 / TC-ISSUE211-033
- **缺陷issue**: https://gitcode.com/openlibing/openlibing-ops/issues/259
- **严重级别**: 严重（核心指标计算公式错误）
- **状态**: 已关闭（closed，2026-10-15；关闭评论附修复截图）
- **复现步骤**:
  1. 进入资源运营看板的资源总览页面
  2. 分别计算“独占池NPU利用率”“共享池NPU利用率”字段值
- **实际结果**: 独占池/共享池 NPU 使用率计算公式与预期口径不一致（预期：项目NPU使用率 = Σ(项目所使用资源池内所有物理机的 NPU 占用总时长) / (Σ(资源池每个物理机NPU卡数) × 统计周期)）
- **预期结果**: 独占池NPU使用率等于Σ(独占NPU资源池使用卡时) / 独占资源池总卡时*100%；共享池NPU使用率等于Σ(共享NPU资源池使用卡时) / 共享资源池总卡时*100%
- **影响范围**: 资源运营看板项目效率表格「独占池NPU利用率」「共享池NPU利用率」两列指标值
- **复现概率**: 100%

#### #266: 资源效率运营看板的NPU使用率与工程效率运营看板的NPU使用率数据不一致

- **关联用例**: TC-ISSUE211-029 / 030 / 031
- **缺陷issue**: https://gitcode.com/openlibing/openlibing-ops/issues/266
- **严重级别**: 一般（跨看板口径不一致）
- **状态**: 已关闭（closed，2026-10-15）
- **复现步骤**:
  1. 进入资源运营看板的资源总览页面
  2. 分别计算“NPU使用率”“独占池NPU使用率”“共享池NPU使用率”字段值，与工程效率运营看板同指标对拍
- **实际结果**: 资源效率运营看板的NPU使用率与工程效率运营看板的NPU使用率数据不一致
- **预期结果**: NPU使用率等于Σ(NPU资源池使用卡时) / 资源池总卡时*100%（两看板同源同口径）
- **影响范围**: 资源运营看板项目效率表格「NPU使用率」「独占池NPU使用率」「共享池NPU使用率」三列指标值
- **复现概率**: 100%

#### #267: 流水线资源效率的NPU使用(占用)平均消耗(卡时)列名错误

- **关联用例**: TC-ISSUE211-049 / TC-ISSUE211-055
- **缺陷issue**: https://gitcode.com/openlibing/openlibing-ops/issues/267
- **严重级别**: 一般（文案级）
- **状态**: 已关闭（closed，2026-10-15；关闭评论附修复截图）
- **复现步骤**:
  1. 进入资源运营看板项目效率表格下钻流水线效率PR表格页面
  2. 查看“NPU使用（占用）平均消耗（卡时）”字段

- **实际结果**: 流水线资源效率的NPU使用(占用)平均消耗(卡时)列名错误
