#### ISSUE-350: [缺陷] 工程效率运营看板下钻资源环境的PR与Nightly的NPU平均消耗(卡时)去NPU消耗非0次数

- **关联用例**: TC-ISSUE331-027（PR流水线）、TC-ISSUE331-028（Nightly流水线）
- **缺陷issue**: https://gitcode.com/openlibing/openlibing-ops/issues/350
- **严重级别**: 一般（指标口径变更遗漏，不影响存量功能）
- **状态**: 已修复关闭（复测通过，2026-11-13）
- **复现步骤**:
  1. 进入工程能力运营看板 → 资源环境下钻页面
  2. 查看 PR 流水线与 Nightly 流水线的 NPU 消耗指标
- **实际结果**: 指标仍为「NPU平均消耗(卡时)」，未按需求变更为「NPU消耗非0数」
- **预期结果**: PR 流水线与 Nightly 流水线均展示「NPU消耗非0数」，指标说明同步修改
- **影响范围**: 工程能力运营看板-资源环境下钻页面的 PR/Nightly 流水线 NPU 指标展示
- **复现概率**: 100%

#### ISSUE-351: [缺陷] PR门禁看板、开源项目运营看板-PR流水线，导出数据，代码量字段位修改为代码规模

- **关联用例**: TC-ISSUE331-029
