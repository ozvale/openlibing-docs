# 测试设计 - ISSUE-043 测试质量看板（遗留问题）

## 1. 设计概述

本Issue的测试设计基于开发设计文档（Issue #43 描述正文），覆盖以下功能点：F1 双维度视角、F2 L1 概览（KPI+列表）、F3 L2/L3 下钻、F4 趋势折线图、F5 导出按钮、F6 数据源接口，并按测试策略覆盖 UI/API/性能/安全四个维度。

### 1.1 设计原则

- 手工用例与自动化用例分离
- 自动化用例需标注脚本位置
- 每个用例需记录用例类型
- 每个功能点需标注所采用的测试设计方法

### 1.2 用例类型定义

| 类型代码 | 类型名称 | 说明 |
|----------|----------|----------|
| manual | 手工执行 | 需要人工操作执行 |
| auto_ui | 自动化-UI | UI自动化测试脚本 |
| auto_api | 自动化-API | API接口自动化测试脚本 |
| auto_perf | 自动化-性能 | 性能测试脚本 |
| auto_sec | 自动化-安全 | 安全测试脚本 |

### 1.3 测试设计方法

- [x] 等价类划分（Equivalence Partitioning）
- [x] 边界值分析（Boundary Value Analysis）
- [x] 决策表测试（Decision Table Testing）—— aspect × productId/projectId 参数组合
- [ ] 状态迁移测试（State Transition Testing）
- [x] 场景法（Use Case / Scenario Testing）—— L1→L2→L3 下钻与面包屑返回
- [x] 错误推测法（Error Guessing）—— 非法参数、无凭证访问
