### 缺陷详情

#### DEFECT-01: detail 接口分页超界参数返回全量数据

- **关联用例**: TC-ISSUE043-015

- **缺陷issue**: [issue #112](https://gitcode.com/openlibing/openlibing-ops/issues/112)

- **严重级别**: 一般（L1 用例，正常交互路径有规避措施）

- **状态**: **已修复**（2026-08-31 复测验证通过）

- **复现步骤**:

  1. 已登录 beta 环境会话
  2. `POST https://beta.openlibing.com/gateway/openlibing-ops/common/detail`，请求体 `{"category": "issue-legacy-detail", "aspect": "organization", "startDate": "2026-07-30", "endDate": "2026-08-28", "productId": "", "projectId": "", "repoUrl": "", "page": 9999, "pageSize": 10}`

- **实际结果（首轮 2026-08-28）**: 返回全量 26 条记录（records 长度 26，超出 pageSize=10）

- **预期结果**: 超界页码应返回空 records（分页边界截断）

- **影响范围**: 仅 API 层直接传入超界页码时触发；正常 UI 分页交互由前端分页器控制页码范围（1\~3），用户正常操作不受影响

- **复现概率（首轮）**: 100%（已二次探针复核确认）

- **复测记录（2026-08-31）**: `pytest ...::test_api_quality_risk_detail_paging_015 --env=test` → **1 passed**。page=9999 返回空 records（0 条）、pageSize=1 时 records=1（≤1）、pageSize=1 与 10 的 total 一致（35=35，数据量 26→35 为正常数据增长）。修复验证通过，缺陷关闭
