## 2. 测试过程

### 2.1 功能测试专项

**1.权限管控测试**: 使用不同成员权限分别打开内部、外部开源仓，验证访问控制逻辑。

* **对应task(issueID)链接:** https://gitcode.com/openlibing/openlibing-anti-poison/issues/9
* **预期结果**: 系统管理员、项目管理员、仓库成员、项目成员均能正常打开内部及外部开源仓；游客（未登录）无法打开内部开源仓，但能正常打开外部开源仓。
*    详细步骤验证：
       1. [步骤] 用户已登录且角色为“系统管理员，尝试打开“内部开源仓” -> [预期] 正常打开
       2. [步骤] 用户已登录且角色为“系统管理员，尝试访问【开源仓】 -> [预期] 正常打开
       3. [步骤] 登录账号角色为“项目管理员”，尝试访问【内部开源仓】 -> [预期] 正常打开
       4. [步骤] 登录账号角色为“项目管理员”，尝试访问【内部开源仓】(重复项/校验) -> [预期] 正常打开
       5. [步骤] 登录账号角色为“仓库成员”，尝试访问【内部开源仓】 -> [预期] 正常打开
       6. [步骤] 登录账号角色为“仓库成员”，尝试访问【开源仓】 -> [预期] 正常打开
       7. [步骤] 登录账号角色为“项目成员”，尝试访问【内部开源仓】 -> [预期] 正常打开
       8. [步骤] 登录账号角色为“项目成员”，尝试访问【开源仓】 -> [预期] 正常打开
       9. [步骤] 未登录以“游客”身份访问，尝试访问【内部开源仓】 -> [预期] 无法打开（应提示无权限或跳转登录）
       10. [步骤] 未登录以“游客”身份访问，尝试访问【开源仓】 -> [预期] 正常打开
* **测试结果**： Passed
