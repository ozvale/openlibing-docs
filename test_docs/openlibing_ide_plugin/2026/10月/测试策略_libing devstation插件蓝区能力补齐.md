### 1.2 需求摘要

> 从需求串讲（2026-10-23）+ 用户表述需求信息提炼，**禁止超出范围**。

**业务目标**：devstation 为提供任务临时执行环境的 IDE 插件（一站式作业平台，执行时申请资源、执行后直接释放）。本次补齐其蓝区能力：由原本通过 **yml 文件**进行任务及所需环境识别，改为**可配置化环境**；由直接对接 hidevlab 改为**通过中间平台灵枢对接**，为后续训练任务/推理任务适配打基础。本次仅支持**可视化配置自定义任务**，可一键执行任务、输出任务日志/结果、拉取产物，任务失败可重试并提供调测功能。

**核心功能点**（本 issue 范围 = devstation 能力补齐）：

1. **可配置化环境**：环境识别由 yml 文件改为可视化配置——可选择环境类型、规格、镜像，配置任务内容；
2. **灵枢对接**：devstation 由直接对接 hidevlab 改为经**灵枢中间平台**对接（资源申请/资源配置/任务执行/资源释放全由插件完成）；
3. **自定义任务可视化配置**：仅支持自定义任务，配置项 = 环境类型 + 规格 + 镜像 + 任务内容；
4. **一键执行**：配置完成后一键完成任务执行；
5. **任务产物**：输出任务日志、任务结果、拉取产物；
6. **失败重试**：任务失败可重试；
7. **调测功能**：提供任务调测能力。

**业务规则 / 边界**：

- devstation 走**灵枢提供的接口**（资源申请→配置→执行→释放全链路）；
- resource-manager（持久化作业平台）走 hidevlab 接口，与本 issue 的资源申请口径不同（插件合一见 issue 61）；
- **三分接口尚未提供**（串讲确认）：灵枢接口未就绪，评审基于 ide 插件 demo；
- 本次**仅支持自定义任务**（训练任务/推理任务适配为后续铺垫，不在本次范围）；
- 执行时申请资源、执行后直接释放（临时执行环境语义）。

**不涉及（禁止发散）**：插件合一与账户体系整改（对接 hidevlab、废弃 openlibing）归 issue 61 覆盖；训练/推理任务适配不在本次范围；不改变 resource-manager 的 hidevlab 对接口径。

### 1.5 测试策略

- 手工测试（主链路，IDE 插件操作 + 两端观测）：
  - 可配置化环境：环境类型/规格/镜像可视化选择与展示，配置合法性校验；
  - 自定义任务：任务内容配置 + 环境组合，空值/非法输入校验；
  - 一键执行：配置完成一键执行，观测灵枢链路（申请→配置→执行→释放）全流程；
  - 任务产物：任务日志/结果展示、产物拉取；
  - 失败重试：任务失败后重试成功；
  - 调测功能：调测入口与行为；
  - 全流程分步执行：任务按 资源申请→环境配置→代码同步→任务执行→日志获取→产物拉取→资源释放 一步步执行（TC-ISSUE60-006）；
  - 失败报错：各环节失败均准确报错失败原因并指导排查（TC-ISSUE60-013）；
  - 资源生命周期：最大占用时长（申请后自动释放）/ 保留时长（任务结束自动释放）/ 手动释放（TC-ISSUE60-014/015/016）；
  - 异常场景：执行时资源申请失败、释放异常、日志/产物缺失；
  - 灵枢接口未就绪用例标记 block，就绪后补执行。
- 自动化测试：插件 UI 自动化依赖 IDE 环境与灵枢接口，接口未就绪前以手工为主；灵枢接口就绪后可补 `auto_api`（任务执行链路），脚本位置 `src/automation/software-cicd/api/...`（待接口就绪后登记）。
