## 1. 结论摘要

本仓库包含两款 IDE 扩展：**ResourceManager**（`local-build/`）与 **DevStation**（`DevStation/`），用于 HidevLab / OpenLibing 登录、远程环境管理、SSH/rsync 代码同步、YAML 任务编排与远程执行。

**攻击面口径（LOCALHOST_DESKTOP）：**

- 扩展**不对外监听端口**，不存在「无前提互联网直打产品服务」类 **Tier 1** 发现。
- 主要外部触发面包括：`vscode://` **深链登录回调**、HidevLab **HTTPS API**、用户触发的 **SSH/rsync**、以及 **CI `pull_request_target`** 对 fork PR 的检出策略。
- 本地威胁包括：**其他已安装扩展**调用命令、**恶意/被篡改工作区 YAML**、**Webview 渲染不可信后端字段**。

**相对 2026-09-03 基线（`088fb81`）的变化：**

| 类型     | 说明                                                                                                                                                                            |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 已修复   | HidevLab 网页回调换取 `sessionId` 失败时，现通过 `handleHidevLabTokenExpired` 清空会话并引导重登，不再保留无效 `authTicket` 半登录态（`local-build/src/auth/AuthService.ts`）   |
| 新增控制 | `malicious-code-pr-scan.yml`、`sca-pr-scan.yml`、`code-metrics-scan.yml`；pre-commit 工作流与 action 版本对齐                                                                   |
| 持续风险 | TLS 校验关闭、SSH 主机密钥不校验、`openlibing.getUserTokenInfo` 暴露令牌、HidevLab 深链无 state、设备密码 LevelDB 明文、YAML `run` 本地/远程执行、CI `allow-unsafe-pr-checkout` |

**正向控制（已存在）：** OpenLibing 回调校验 `openLibingState`；用户 token 使用 `SecretStorage`；pre-commit 含 gitleaks / detect-secrets；MR 侧增加恶意代码与 SCA 扫描工作流。

### 1.1 总体风险评级

采用四档：**Critical / Elevated / Moderate / Low**。当前无 T1、无 Critical 单条发现，但存在 **5 条 Important**（TLS、SSH MITM、令牌命令暴露、HidevLab 深链 CSRF、YAML/远程命令执行）→ **Elevated**。

### 2.2 部署与暴露（Component Exposure）

| 组件               | 监听地址    | 认证屏障                 | 外部可达             | 最低利用前提                               |
| ------------------ | ----------- | ------------------------ | -------------------- | ------------------------------------------ |
| 两款扩展主进程     | 无 TCP      | IDE 用户会话             | 否（本地）           | 本地代码执行或用户交互                     |
| HidevLabHttpClient | 出站 HTTPS  | sessionId Cookie         | 是（到 HidevLab）    | 网络位置或恶意 CA/关闭 TLS 校验            |
| SSH/rsync 客户端   | 出站 22 等  | 密钥/密码                | 是（到实验室主机）   | 网络 MITM（配合 StrictHostKeyChecking=no） |
| vscode:// URI      | OS 协议处理 | 部分（OpenLibing state） | 是（需用户点击链接） | **用户点击** 恶意深链                      |
| GitCode CI         | 平台调度    | ROBOT_TOKEN 等           | PR/fork 场景         | 恶意 PR + `pull_request_target` 策略       |

**信任边界：**

1. **Application**：IDE 扩展进程 + Webview（同源 CSP 由 VS Code 约束，但脚本内仍用 `innerHTML`）。
2. **External**：HidevLab/OpenLibing、远程 SSH 主机、GitCode Runner、浏览器登录页。

## 4. 安全发现（按可利用性 Tier 排序）

### Tier 2

#### FIND-01 — HidevLab 客户端禁用 TLS 证书校验

| 属性          | 值                                                                                                       |
| ------------- | -------------------------------------------------------------------------------------------------------- |
| 可利用性 Tier | **T2**（需不可信网络或恶意网关；非无交互远程直打扩展）                                                   |
| 修复工作量    | **Medium**                                                                                               |
| 严重度        | **Important**                                                                                            |
| CVSS 4.0      | **8.2** — `CVSS:4.0/AV:N/AC:H/AT:N/PR:N/UI:N/VC:H/VI:H/VA:N/SC:H/SI:H/SA:N`                              |
| CWE           | [CWE-295](https://cwe.mitre.org/data/definitions/295.html): Improper Certificate Validation              |
| OWASP         | **A02:2025 – Security Misconfiguration**                                                                 |
| 证据          | `local-build/src/utils/HidevLabHttpClient.ts` 构造函数：`process.env.NODE_TLS_REJECT_UNAUTHORIZED = "0"` |
| 影响          | 相邻网络或企业 TLS 拦截场景下，可窃听/篡改 sessionId 与 API 数据                                         |
| 建议          | 移除全局关闭校验；按环境使用受信 CA 或证书固定；仅在显式调试开关且非生产路径启用                         |

#### FIND-02 — SSH/rsync 禁用主机密钥校验（MITM）

| 属性          | 值                                                                                                                                              |
| ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| 可利用性 Tier | **T2**                                                                                                                                          |
| 修复工作量    | **Medium**                                                                                                                                      |

| CWE           | [CWE-322](https://cwe.mitre.org/data/definitions/322.html): Key Exchange without Entity Authentication                                          |

| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
